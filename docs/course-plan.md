# Программа курса

> **Состояние:** главы 1–12 написаны (`content/`). Их фактический состав шагов в нескольких местах отличается от таблиц ниже — расхождения перечислены в `docs/authoring-process.md`, раздел «Фактическое состояние». Для глав 13–17 таблицы ниже — рабочий план.

Курс состоит из **трёх частей**:

1. **Основы** (главы 1–6). Учим базовые сущности PixiJS и собираем статичное, но кликабельное игровое поле.
2. **Игра** (главы 7–14). Пишем логику match-3, анимации, интерфейс, экраны, эффекты и звук. На выходе — играбельная учебная версия Puzzling Potions.
3. **Глубже** (главы 15–17). Разбираем оригинальный Puzzling Potions и то, как PixiJS устроен внутри.

Каждая глава состоит из 5–10 **шагов**. Шаг — это одна идея и одно небольшое изменение кода с видимым результатом. В конце главы есть **практикум**: самостоятельное задание без готового решения в тексте (решение показывается только по кнопке).

Помимо шагов основного трека в главах встречаются **врезки «Под капотом»**: необязательные блоки о том, как устроена внутренняя механика. Это главный инструмент для цели «разобраться максимально».

Обозначения в таблицах:
- **API** — что из PixiJS впервые вводится в шаге.
- **Результат** — что ученик видит в превью после шага.

## Карта покрытия API

Позволяет проверить, что курс действительно покрывает PixiJS «максимально».

| Область | API | Глава |
|---|---|---|
| Приложение | `Application`, `init`, `stage`, `renderer`, `ticker`, `screen`, `resizeTo` | 1 |
| Отображение | `Sprite`, `Container`, `Graphics`, `GraphicsContext`, `Text`, `BitmapText`, `HTMLText`, `TilingSprite`, `NineSliceSprite`, `AnimatedSprite`, `Mesh`, `ParticleContainer` | 2, 3, 4, 8, 9, 10, 12, 16 |
| Трансформации | `position`, `scale`, `rotation`/`angle`, `anchor`, `pivot`, `skew`, `toGlobal`/`toLocal`, `getBounds` | 2, 3 |
| Внешний вид | `alpha`, `tint`, `visible`, `blendMode`, `mask`, `filters` | 2, 4, 12 |
| Ресурсы | `Assets` (`load`, `add`, `init`, `loadBundle`, `backgroundLoad`, `unload`), `Texture`, `TextureSource`, `Spritesheet` | 2, 5 |
| События | `eventMode`, pointer-события, `FederatedPointerEvent`, `hitArea`, `cursor`, `interactiveChildren` | 6 |
| Время | `Ticker`, `deltaTime`, `deltaMS`, `onRender`, `UPDATE_PRIORITY` | 8 |
| Фильтры | `BlurFilter`, `ColorMatrixFilter`, `Filter`, pixi-filters | 12, 16 |
| Рендеринг | WebGL/WebGPU, батчинг, `isRenderGroup`, culling, `RenderTexture`, `generateTexture`, `cacheAsTexture` | 16 |
| Экосистема | `@pixi/ui`, `@pixi/sound`, AssetPack, Spine, PixiJS DevTools | 1, 5, 10, 13, 14, 15 |

Не входит в курс (упоминаем ссылкой): `DOMContainer`, `@pixi/layout`, `@pixi/react`, сторонние физические движки.

## Объём

Примерно 17 глав и 120–140 шагов. Ориентир для ученика — 25–35 часов.
