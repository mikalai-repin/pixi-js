Обмен фишек работает, но выглядит как движение конвейера: фишка трогается с места сразу на полной скорости и так же резко останавливается. Настоящие предметы так не двигаются. Им нужно время, чтобы разогнаться и затормозить. В анимации это передают **функциями плавности** (easing).

## Что такое функция плавности

В твине есть строчка, которую мы пока не использовали:

```ts
const k = ease(t);
```

`t` — доля прошедшего **времени**, от 0 до 1. А `k` — доля пройденного **пути**. Функция плавности переводит одно в другое. У `linear` они равны, и скорость постоянна. А если, например, `k` растёт сначала быстро, а потом медленно, объект резко стартует и плавно тормозит.

Удобнее всего смотреть на график: по горизонтали — время, по вертикали — путь, пунктир — цель.

- **`linear`** — прямая: равномерное движение;
- **`quadOut`** — `1 − (1 − t)²`: быстрый старт, плавная остановка. За половину времени пройдено три четверти пути. Это самый частый выбор для интерфейсов и перемещений. «Out» в названии означает, что плавным получается **конец** движения;
- **`backOut`** — проскакивает цель примерно на 10 % и возвращается. Такой **перелёт** (overshoot) придаёт движению упругость, как будто объект на пружинке;
- **`singleBounce`** — разгон, удар о дно и один небольшой отскок. Такую кривую оригинальная игра использует для падения фишек.

Обратите внимание: `k` может выходить за пределы от 0 до 1, как у `backOut`. Ничего страшного: `lerp` с `t = 1.1` честно вернёт точку за концом отрезка.

## Пишем функции

Добавьте в `tween.ts` после `linear`:

```ts tween.ts
/** Быстрый старт и плавная остановка: квадратичное замедление */
export const quadOut: Easing = (t) => 1 - (1 - t) * (1 - t);

/** Как quadOut, но в конце проскакивает цель примерно на 10 % и возвращается */
export const backOut: Easing = (t) => {
  const s = 1.70158;
  const p = t - 1;
  return p * p * ((s + 1) * p + s) + 1;
};
```

Число `1.70158` в `backOut` подобрано так, чтобы перелёт был ровно 10 %: максимум функции — 1,1 при `t ≈ 0.58`. Это классическая формула Роберта Пеннера, автора функций плавности, на которых основаны почти все библиотеки анимации. Та же формула и та же константа используются в GSAP.

Теперь «одиночный отскок». В оригинале он задан кривой Безье через плагин GSAP `CustomEase`. Мы соберём похожую кривую из двух парабол:

```ts tween.ts
/** Когда падающая фишка впервые касается дна: доля времени */
const LAND_TIME = 0.55;
/** Высота отскока: доля всего пути */
const BOUNCE_HEIGHT = 0.15;

/** Падение с ускорением и один небольшой отскок, как у фишек в оригинале */
export const singleBounce: Easing = (t) => {
  // Падение: путь растёт как квадрат времени, то есть с ускорением
  if (t < LAND_TIME) return (t / LAND_TIME) ** 2;
  // Отскок: невысокая парабола вверх и обратно
  const u = (t - LAND_TIME) / (1 - LAND_TIME);
  return 1 - BOUNCE_HEIGHT * 4 * u * (1 - u);
};
```

- до `LAND_TIME` фишка падает, и путь растёт как квадрат времени — так падают предметы под действием тяжести;
- после касания `u` заново идёт от 0 до 1, а `4u(1 − u)` — парабола, которая в начале и в конце равна 0, а посередине 1. Умножаем её на высоту отскока и вычитаем из 1: фишка подпрыгивает на 15 % пути и возвращается.

Любая функция плавности должна давать `0` при `t = 0` и `1` при `t = 1`. Иначе объект начнёт движение с прыжка или не доедет до цели. Проверьте: у всех четырёх функций это так.

## Используем

Обмен в оригинале длится 0,2 секунды с `quad.out`. В `Piece.ts`:

```ts Piece.ts {1,6}
import { quadOut, tween } from './tween';
// …

  /** Плавно перемещает фишку в точку (x, y) внутри поля */
  async animateMove(x: number, y: number) {
    await tween(this.ticker, this, { x, y }, { duration: 0.2, ease: quadOut });
  }
```

А заодно анимируем **неверный ход**: фишки съезжаются и возвращаются, чтобы игрок видел, что свайп сработал, но ход не засчитан. В `Board.ts` перепишите конец `onSwipe`:

```ts Board.ts {1,6-12}
    const valid = this.isValidMove(from, to);
    this.processing = true;
    // Выбранная фишка рисуется поверх остальных — пусть она и едет сверху
    this.select(piece);
    await this.swap(from, to);
    if (valid) {
      this.process();
    } else {
      // Ход без совпадений: фишки съезжаются и возвращаются на свои места
      console.log('Ход не создаёт совпадений');
      await this.swap(from, to);
    }
    this.processing = false;
```

Второй `swap` тех же клеток возвращает всё как было: и модель, и фишки.

## Что получилось

Сделайте ход: фишки стартуют резко и мягко «припарковываются» в клетках. Попробуйте неверный ход: фишки съезжаются и разъезжаются обратно за 0,4 секунды. Проверка подтвердила, что после неверного хода сетка не меняется, а фишки возвращаются точно в свои клетки.

## Эксперименты

Нажмите `3` для замедления и по очереди подставьте в `animateMove` разные функции:

- `linear` — сравните с `quadOut`: разница в конце движения хорошо видна;
- `backOut` — фишки проскакивают свои клетки и возвращаются. Для обмена выглядит слишком игриво, но для появления кнопок или попапов — в самый раз;
- `singleBounce` — фишки «падают» друг на друга по горизонтали и подпрыгивают. Странно: отскок уместен только там, где есть «пол». Мы используем его для падения в следующем шаге.

Верните `quadOut`.

::: deep Под капотом: In, Out и InOut
У большинства функций плавности три варианта:

- **In** — медленный старт, резкий конец: `quadIn(t) = t²`. Подходит для того, что уходит с экрана или падает с ускорением;
- **Out** — резкий старт, медленный конец: `quadOut(t) = 1 − (1 − t)²`. Это `In`, «отражённый» по времени и пути: `out(t) = 1 − in(1 − t)`;
- **InOut** — медленно в начале и в конце, быстро в середине. Первая половина — сжатый `In`, вторая — сжатый `Out`.

Кроме `quad` (вторая степень) бывают `cubic` (третья), `quart`, `quint`, а также `sine`, `expo`, `circ`, `elastic` и `bounce`. Чем выше степень, тем резче разгон или торможение. Посмотреть и сравнить кривые удобно на странице GSAP Ease Visualizer.

Первая половина нашего `singleBounce` — это `quadIn`, растянутый на `LAND_TIME`.
:::
