Приложение работает, но canvas не виден, потому что не добавлен в документ. Сейчас мы это исправим и заодно разберёмся, что за прямоугольник появится на экране.

## `app.canvas`

После `init()` у приложения есть свойство **`app.canvas`** — обычный DOM-элемент `HTMLCanvasElement`. PixiJS рисует в него, но не решает, где он будет на странице. Это делаете вы, как с любым другим элементом:

```ts main.ts {6-7}
import { Application } from 'pixi.js';

const app = new Application();
await app.init();

// Добавляем canvas приложения на страницу
document.body.appendChild(app.canvas);
```

Canvas можно вставить в любой контейнер, а не только в `body`. Например, на обычном сайте игра может жить в `<div id="game">` посреди статьи.

::: task
Добавьте `app.canvas` в `document.body`.
:::

## Что получилось

В превью появился **чёрный прямоугольник** в левом верхнем углу. Это и есть canvas PixiJS. Сцена пока пуста, поэтому каждый кадр рендерер просто заливает canvas цветом фона.

Почему именно чёрный и именно такого размера? Потому что мы не передали в `init()` никаких параметров, и PixiJS взял значения по умолчанию:

| Параметр | По умолчанию |
|---|---|
| Ширина × высота | 800 × 600 пикселей |
| Цвет фона | `0x000000` — чёрный |

Превью узкое, поэтому вы видите только часть canvas: он шире, чем окно. Если перетащить разделитель между редактором и превью влево, canvas будет виден целиком.

## Canvas — это просто элемент

Раз canvas — обычный DOM-элемент, к нему применимо всё, что вы знаете о DOM. Попробуйте добавить рамку:

```ts
app.canvas.style.border = '4px solid hotpink';
```

Рамка нарисована браузером вокруг элемента, а не PixiJS внутри него. Такое разделение стоит запомнить:

- **снаружи** canvas — территория браузера: CSS, расположение на странице, размер элемента;
- **внутри** canvas — территория PixiJS: всё, что нарисовано на сцене.

::: deep Под капотом: два размера у одного canvas
У canvas два разных размера. Атрибуты `width` и `height` задают, сколько в нём **пикселей** — это «разрешение холста». CSS-свойства `style.width` и `style.height` задают, сколько места элемент **занимает на странице**. Если холст 400×300, а на странице он растянут CSS до 800×600, браузер увеличит картинку, и она станет мыльной.

PixiJS управляет первым размером, а второй по умолчанию совпадает с ним. Это различие станет важным в следующем шаге, когда мы будем говорить о `resolution` и экранах с высокой плотностью пикселей.
:::
