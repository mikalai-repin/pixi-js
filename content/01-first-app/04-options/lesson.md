Чёрный прямоугольник 800 × 600 — не лучший фон для игры про зелья. Метод `init()` принимает объект параметров, которыми настраивается почти всё в приложении. Разберём самые важные.

## Цвет фона: `background`

```ts
await app.init({ background: '#1e1035' });
```

PixiJS понимает цвет во многих форматах, и все они означают одно и то же:

| Формат | Пример |
|---|---|
| Строка HEX | `'#1e1035'` |
| Число HEX | `0x1e1035` |
| Название CSS | `'rebeccapurple'` |
| Массив RGB (0..1) | `[0.12, 0.06, 0.21]` |
| Объект | `{ r: 30, g: 16, b: 53 }` или `{ h: 263, s: 54, l: 14 }` |

Числовая запись `0x1e1035` — это тот же HEX, только как число JavaScript: `0x` вместо `#`. В коде на PixiJS она встречается очень часто, в том числе в оригинальной Puzzling Potions.

Прозрачность фона задаётся отдельно, параметром `backgroundAlpha` от `0` до `1`. При `backgroundAlpha: 0` canvas станет прозрачным, и сквозь него будет видна страница.

## Размер: `width`, `height` и `resizeTo`

Фиксированный размер задаётся так:

```ts
await app.init({ width: 400, height: 300 });
```

Но игре обычно нужен весь экран, причём размер окна может меняться. Для этого есть **`resizeTo`**: передайте ему `window` или любой DOM-элемент, и PixiJS будет подгонять canvas под его размер, в том числе при изменении размера окна.

```ts
await app.init({ resizeTo: window });
```

::: tip
Если указаны и `resizeTo`, и `width`/`height`, побеждает `resizeTo`: при первом же пересчёте размер станет равен размеру окна.
:::

## Сглаживание: `antialias`

У наклонных и круглых краёв фигур бывают «лесенки» из пикселей. **Сглаживание** (antialiasing) смягчает их за счёт полупрозрачных пикселей по краям. По умолчанию оно выключено: на слабых устройствах это немного экономит ресурсы. Для нашей игры включим.

```ts
await app.init({ antialias: true });
```

Разницу вы увидите позже, когда начнём рисовать фигуры и поворачивать картинки.

::: task
Передайте в `init()` три параметра: фон `'#1e1035'`, `resizeTo: window` и `antialias: true`.
:::

```ts main.ts {4-8}
import { Application } from 'pixi.js';

const app = new Application();
await app.init({
  background: '#1e1035',
  resizeTo: window,
  antialias: true,
});

document.body.appendChild(app.canvas);
```

## Что получилось

Теперь превью целиком залито тёмно-фиолетовым. Потяните разделитель между панелями: canvas подстраивается под новый размер. Здесь «окно» для PixiJS — это превью, потому что код выполняется внутри него.

## Выбор рендерера: `preference`

По умолчанию PixiJS выбирает WebGL. Параметр **`preference`** позволяет попросить другой рендерер:

```ts
await app.init({ preference: 'webgpu' });
```

Если браузер не поддерживает WebGPU, PixiJS спокойно откатится на WebGL. Попробуйте значения `'webgpu'` и `'canvas'` и посмотрите в консоль: строка «Рендерер» покажет, что выбралось на самом деле. Потом уберите `preference`. В курсе мы используем рендерер по умолчанию.

::: deep Под капотом: resolution, autoDensity и чёткость на Retina
На современных телефонах и ноутбуках один «CSS-пиксель» состоит из нескольких физических пикселей экрана. Это соотношение хранится в `window.devicePixelRatio`: на обычном мониторе оно равно `1`, на Retina — `2` или `3`.

Если canvas размером 800 × 600 показать на экране с `devicePixelRatio = 2`, браузер растянет его в два раза, и картинка станет мыльной. Чтобы этого не было, у PixiJS есть два параметра:

- **`resolution`** — во сколько раз больше пикселей будет у холста. При `resolution: 2` canvas «логического» размера 800 × 600 получит 1600 × 1200 настоящих пикселей.
- **`autoDensity: true`** — PixiJS сам выставит CSS-размер элемента обратно в 800 × 600. Холст станет плотнее, но не больше на странице.

```ts
await app.init({
  resizeTo: window,
  resolution: window.devicePixelRatio,
  autoDensity: true,
});
```

Цена такой чёткости — производительность: при `resolution: 2` видеокарте приходится закрашивать в четыре раза больше пикселей. Поэтому в играх `resolution` часто ограничивают. В оригинальной Puzzling Potions стоит `resolution: Math.max(window.devicePixelRatio, 2)`, то есть не меньше двух.

Все координаты в PixiJS задаются в логических пикселях. При любом `resolution` ширина экрана для вашего кода остаётся 800, а не 1600.
:::
