После удаления на поле остаются дыры. В match-3 фишки над дырой **падают вниз** и занимают освободившиеся места. Опишем это падение в модели, а потом повторим его на экране.

## Что должна делать функция

Возьмём один столбец, сверху вниз:

```
было        стало
[3]          [0]
[0]          [0]
[5]   →      [3]
[0]          [5]
[2]          [2]
```

Все непустые клетки «оседают» на дно столбца, сохраняя порядок, а пустые оказываются сверху. Для вида нам нужно знать не только итог, но и **какая фишка куда переехала**: `3` из строки 0 в строку 2, `5` из строки 2 в строку 3. Поэтому функция будет возвращать список перемещений `[откуда, куда]`.

## Алгоритм «нижняя свободная клетка»

Пройдём по столбцу **снизу вверх** и будем помнить `emptyRow` — самую нижнюю клетку, куда можно положить следующую фишку. Вначале это дно. Каждая встреченная фишка опускается в `emptyRow`, и `emptyRow` поднимается на одну клетку вверх. Пустые клетки просто пропускаем.

Добавьте в `grid.ts`:

```ts grid.ts
/**
 * Опускает фишки на пустые клетки под ними.
 * Возвращает список перемещений [откуда, куда], чтобы вид мог передвинуть фишки так же
 */
export function applyGravity(grid: Grid): [Position, Position][] {
  const moves: [Position, Position][] = [];
  const rows = grid.length;
  const columns = grid[0].length;

  for (let column = 0; column < columns; column++) {
    // Идём снизу вверх и запоминаем самую нижнюю свободную клетку столбца
    let emptyRow = rows - 1;
    for (let row = rows - 1; row >= 0; row--) {
      const type = grid[row][column];
      if (type === 0) continue;
      if (row !== emptyRow) {
        grid[emptyRow][column] = type;
        grid[row][column] = 0;
        moves.push([{ row, column }, { row: emptyRow, column }]);
      }
      emptyRow--;
    }
  }

  return moves;
}
```

Если фишка уже лежит в `emptyRow` (под ней нет дыр), она никуда не двигается, и перемещение не записывается.

Проследите алгоритм на примере выше: дно — строка 4, там `2`, она на месте, `emptyRow` становится 3. Строка 3 пустая, пропускаем. В строке 2 лежит `5`, она переезжает в строку 3, `emptyRow` = 2. Строка 1 пустая. В строке 0 лежит `3`, она переезжает в строку 2. Ровно то, что на рисунке.

## Повторяем на экране

В `Board.ts` добавьте метод, который применяет гравитацию к модели и передвигает фишки по списку перемещений:

```ts Board.ts
  /** Роняет фишки на пустые клетки: сначала в модели, потом так же на экране */
  private dropPieces() {
    const moves = applyGravity(this.grid);
    for (const [from, to] of moves) {
      const piece = this.getPiece(from);
      this.setPiece(from, null);
      this.setPiece(to, piece);
    }
    return moves.length;
  }
```

`setPiece` обновляет и массив `pieces`, и `row`/`column` фишки, и её позицию на экране. Порядок перемещений тоже важен: функция двигает фишки снизу вверх, поэтому клетка `to` всегда уже свободна, когда в неё кладут фишку.

Вызовите его в `onSwipe` после удаления совпадений:

```ts Board.ts
    this.popMatches(getMatches(this.grid));
    this.dropPieces();
```

И добавьте `applyGravity` в импорт из `./grid`.

## Что получилось

Сделайте ход, собирающий тройку **по горизонтали**: три фишки исчезнут, а фишки над ними мгновенно опустятся на одну клетку. Дыры теперь всегда **вверху** столбцов. Тройка **по вертикали** уберёт три клетки одного столбца, и фишки над ней упадут сразу на три клетки.

Пустые клетки сверху мы заполним в следующем шаге.

::: deep Под капотом: отличие от оригинала
В оригинальной `match3ApplyGravity` алгоритм другой: она идёт по строкам снизу вверх и для каждой фишки «протаскивает» её вниз обменами, пока под ней пусто. Итоговая сетка и набор перемещений получаются такими же (отличается только их порядок в списке), но кода больше, а каждая фишка двигается по шагу за раз.

Наш вариант с `emptyRow` делает за один проход по столбцу то же самое, и каждую фишку переносит сразу на нужное место. Это хороший пример того, что разбирать оригинал полезно не только чтобы копировать, но и чтобы видеть, где можно проще. В главе 15 мы ещё вернёмся к таким местам.
:::
