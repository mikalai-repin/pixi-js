Сердце любой match-3 — функция, которая находит на поле **совпадения**: три и больше одинаковых фишки подряд по горизонтали или вертикали. Напишем её и подсветим найденные совпадения после каждого обмена.

## Что возвращать

Совпадение — это список клеток, например `[{ row: 2, column: 1 }, { row: 2, column: 2 }, { row: 2, column: 3 }]`. Совпадений на поле может быть несколько, поэтому функция возвращает **список списков**: `Position[][]`. Пустой список означает, что совпадений нет.

## Идея: серии в линиях

Пройдём по каждой строке слева направо и будем отслеживать **серию** — сколько одинаковых фишек идут подряд:

```
строка:   [2][5][5][5][5][1][3]
серии:    [2] [5  5  5  5] [1] [3]
                 ↑ длина 4 ≥ 3 — совпадение
```

Когда тип меняется, серия заканчивается. Если в ней было три клетки или больше, это совпадение. Потом то же самое для столбцов, сверху вниз.

Обратите внимание: четыре в ряд — это **одно** совпадение из четырёх клеток, а не два пересекающихся по три.

## Код

Строки и столбцы обрабатываются одинаково, отличается только направление обхода. Поэтому напишем одну функцию с параметром `orientation`. Добавьте в `grid.ts`:

```ts grid.ts
/** Одна и та же ли это клетка */
export function samePosition(a: Position, b: Position) {
  return a.row === b.row && a.column === b.column;
}

/**
 * Все совпадения в сетке: группы из matchSize и более одинаковых фишек подряд
 * по горизонтали или вертикали. Пустые клетки (0) совпадений не образуют.
 */
export function getMatches(grid: Grid, matchSize = 3): Position[][] {
  return [...getLineMatches(grid, matchSize, 'horizontal'), ...getLineMatches(grid, matchSize, 'vertical')];
}

/** Совпадения только в строках или только в столбцах */
function getLineMatches(grid: Grid, matchSize: number, orientation: 'horizontal' | 'vertical') {
  const matches: Position[][] = [];
  const rows = grid.length;
  const columns = grid[0].length;
  // Внешний цикл идёт по линиям (строкам или столбцам), внутренний — вдоль линии
  const lines = orientation === 'horizontal' ? rows : columns;
  const length = orientation === 'horizontal' ? columns : rows;

  for (let line = 0; line < lines; line++) {
    let current: Position[] = [];
    let currentType: PieceType | undefined;

    for (let step = 0; step < length; step++) {
      const position = orientation === 'horizontal' ? { row: line, column: step } : { row: step, column: line };
      const type = getType(grid, position);

      if (type && type === currentType) {
        // Тот же тип — серия продолжается
        current.push(position);
      } else {
        // Другой тип — серия закончилась. Если она достаточно длинная, это совпадение
        if (current.length >= matchSize) matches.push(current);
        current = [position];
        currentType = type;
      }
    }
    // Серия, дошедшая до конца линии
    if (current.length >= matchSize) matches.push(current);
  }

  return matches;
}
```

Две детали, которые легко упустить:

- **`if (type && …)`** — пустая клетка (`0`) никогда не продолжает серию. Без этой проверки три пустые клетки подряд считались бы совпадением, и в шаге 5 игра пыталась бы «убрать» пустоту.
- **Проверка после внутреннего цикла.** Серия, которая тянется до самого края, не встретит «другой тип», и без последней проверки совпадение у правого края потерялось бы. Это классическая ошибка при подсчёте серий.

## Подсвечиваем совпадения

`samePosition` нам понадобится в следующем шаге. А совпадения проверим в `Board.ts`: после каждого обмена подсветим все фишки, которые входят в тройки. Добавьте в класс метод:

```ts Board.ts
  /** Подсвечивает все фишки, которые сейчас входят в совпадения */
  private highlightMatches() {
    const matches = getMatches(this.grid);
    for (const piece of this.pieces) piece?.setHighlight(piece === this.selected);
    for (const match of matches) {
      for (const position of match) this.getPiece(position)?.setHighlight(true);
    }
    console.log(`Совпадений на поле: ${matches.length}`);
  }
```

Сначала снимаем подсветку со всех фишек, кроме выбранной, потом подсвечиваем совпавшие. И вызовите метод в конце `onSwipe`, после обмена:

```ts Board.ts
    this.highlightMatches();
```

Не забудьте добавить `getMatches` в импорт из `./grid`.

## Что получилось

Найдите на поле место, где обмен двух соседних фишек даёт три в ряд, и сделайте этот свайп. Три фишки подсветятся, а в консоли появится `Совпадений на поле: 1`. Если обменять так, что тройки не получится, в консоли будет `0`.

Попробуйте собрать четыре в ряд или «уголок» — тройку по горизонтали и тройку по вертикали с общей клеткой. Сколько совпадений насчитает функция в каждом случае?

::: deep Под капотом: сложность
Функция проходит по каждой клетке дважды: один раз по строкам, один раз по столбцам. Для поля 9 × 7 это 126 проверок, то есть доли микросекунды. Вызывать её можно сколько угодно часто, хоть каждый кадр.

Это ещё одно преимущество отдельной модели. Если бы мы искали совпадения по спрайтам, сравнивая их текстуры, каждая проверка обращалась бы к объектам сцены, и код был бы и медленнее, и запутаннее.
:::
