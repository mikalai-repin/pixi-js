Осталось сделать очки по-настоящему игровыми. Каскады должны приносить больше, чем обычные ходы, а игрок должен **видеть**, откуда взялись очки: «+30» над исчезнувшей тройкой и «Комбо ×2», когда каскад продолжается. Таких надписей будет много, и у всех один стиль. Пора завести для них свой класс.

В редакторе появилась вкладка `Label.ts` с заготовкой. Больше ничего не менялось.

## Класс Label

В оригинальной игре все надписи сделаны классом `Label`: это `Text` со стилем игры по умолчанию и якорем в центре. Сделаем такой же:

```ts Label.ts
/** Стиль надписей игры по умолчанию */
const defaultLabelStyle: TextStyleOptions = {
  fontFamily: FONT_FAMILY,
  fontSize: 30,
  fill: 0xffffff,
  align: 'center',
  stroke: { color: 0x2c136c, width: 5 },
};

/**
 * Надпись в стиле игры, по умолчанию с якорем в центре.
 * Упрощённая версия Label из Puzzling Potions
 */
export class Label extends Text {
  constructor(text: string | number = '', style: TextStyleOptions = {}) {
    super({ text, style: { ...defaultLabelStyle, ...style } });
    this.anchor.set(0.5);
  }
}
```

- **`TextStyleOptions`** — тип объекта, из которого создаётся `TextStyle`. Все поля необязательные;
- **`{ ...defaultLabelStyle, ...style }`** — стиль по умолчанию, поверх которого записаны переданные поля. `new Label('+30', { fill: 0xffd27f })` — золотая надпись с той же обводкой и шрифтом;
- **якорь в центре** — надписи в игре почти всегда центрируются. Если где-то нужно иначе, якорь можно поменять после создания.

Счёт над полем теперь тоже `Label`. Его стиль — это стиль по умолчанию плюс тень:

```ts main.ts
const scoreText = new Label('Очки: 0', {
  // Тёмная тень отделяет счёт от любого фона
  dropShadow: { color: 0x000000, alpha: 0.4, blur: 2, distance: 3, angle: Math.PI / 2 },
});
// Текстура текста вдвое подробнее экрана: счёт будет увеличиваться и не должен размываться
scoreText.resolution = 2;
```

Строку `scoreText.anchor.set(0.5)` можно удалить: якорь ставит `Label`. А `Text` из импорта `pixi.js` в `main.ts` больше не нужен.

## Очки за комбо

Правило подсчёта сделаем таким: 10 очков за фишку, умноженные на номер раунда каскада. Тройка в первом раунде — 30, тройка во втором — 60, в третьем — 90. Номер раунда `Board` уже передаёт вторым аргументом `onMatch`:

```ts main.ts
/** Очков за одну фишку в совпадении */
const POINTS_PER_PIECE = 10;

board.onMatch = (matches, round) => {
  for (const match of matches) {
    // Каждый следующий раунд каскада умножает очки: ×2, ×3…
    const points = match.length * POINTS_PER_PIECE * round;
    score += points;
    showPoints(match, points);
  }
  if (round > 1) showCombo(round);
  showScore();
};
```

В оригинале формула другая: очко за каждую лопнувшую фишку плюс за каждое совпадение его длина и бонус `число совпадений × номер раунда`. Числа там мельче, но идея та же — каскад ценнее обычного хода.

## Всплывающие очки

«+30» должно появиться в центре исчезнувшего совпадения. Координаты клеток в пикселях даёт `board.getViewPosition`, но это координаты **внутри поля**: его центр — точка (0, 0). Поэтому надпись проще всего добавить в само поле, тогда никакого пересчёта координат не нужно:

```ts main.ts
/** «+30» взлетает из центра совпадения и тает */
async function showPoints(match: Position[], points: number) {
  const label = new Label(`+${points}`, { fontSize: 24, fill: 0xffd27f });
  // Центр совпадения — среднее положение его клеток, в координатах поля
  const views = match.map((position) => board.getViewPosition(position));
  label.x = views.reduce((sum, view) => sum + view.x, 0) / views.length;
  label.y = views.reduce((sum, view) => sum + view.y, 0) / views.length;
  board.addChild(label);
  gsap.to(label, { alpha: 0, duration: 0.4, delay: 0.5 });
  await gsap.to(label, { y: label.y - 50, duration: 0.9, ease: 'quad.out' });
  label.destroy();
}
```

- **центр совпадения** — среднее арифметическое позиций его клеток. Для горизонтальной тройки это центр средней клетки;
- **`board.addChild(label)`** — надпись добавляется последней и рисуется поверх фишек, рамки выбора и маски. На слой фишек маска действует, а на надписи — нет;
- **две анимации сразу** — подъём на 50 пикселей за 0,9 секунды и исчезновение, которое начинается через 0,5 секунды. Вместе получается «взлетела и растаяла»;
- **`destroy` после `await`** — правило из главы 8: надпись уничтожается только после того, как её анимация закончилась. Исчезновение заканчивается одновременно с подъёмом (0,5 + 0,4 = 0,9 секунды), так что к моменту `destroy` оба твина завершены.

Импортируйте `Label` и тип `Position` из `grid`.

## Комбо

```ts main.ts
/** «Комбо ×2» выпрыгивает в центре поля */
async function showCombo(round: number) {
  const label = new Label(`Комбо ×${round}`, { fontSize: 44, fill: 0xffd27f });
  board.addChild(label);
  gsap.fromTo(label.scale, { x: 0, y: 0 }, { x: 1, y: 1, duration: 0.4, ease: 'back.out' });
  await gsap.to(label, { alpha: 0, duration: 0.3, delay: 0.8 });
  gsap.killTweensOf(label.scale);
  label.destroy();
}
```

Позиция не задана, значит надпись стоит в точке (0, 0) поля — в его центре. Она выпрыгивает из нулевого размера с перелётом `back.out`, держится, а через 0,8 секунды растворяется. `killTweensOf(label.scale)` перед уничтожением — на всякий случай: здесь «прыжок» давно кончился, но правило есть правило.

## Что получилось

После хода над исчезающей тройкой взлетает золотое «+30» и тает, а счёт набегает. Если начался каскад, в центре поля выпрыгивает «Комбо ×2», а очки второго раунда — «+60». Мы проверили: после восьми ходов счёт на экране совпал с очками, посчитанными независимо по тому же правилу с умножением на раунд, а все всплывающие надписи уничтожились: число детей у поля вернулось к прежним пяти.

## Эксперименты

- Поставьте «+N» `fontSize` побольше для длинных совпадений: `fontSize: 20 + match.length * 2`. Четвёрка и пятёрка станут заметнее.
- Уберите `label.destroy()` в `showPoints` и сделайте несколько ходов. Внешне ничего не изменится: надписи прозрачные. Но выведите в консоль `board.children.length` — невидимые надписи копятся в дереве сцены, занимают память и каждый кадр обходятся рендерером. Верните `destroy`.
- Добавьте надписи «+N» поворот: `gsap.to(label, { rotation: (Math.random() - 0.5) * 0.6, duration: 0.9 })`. Мелкая случайность делает повторяющиеся эффекты живее, этим приёмом мы займёмся в главе 12.

## Итоги главы

Теперь в игре есть счёт, таймер, подсказка и всплывающие очки. Вы знаете:

- **`Text`** рисует строку на canvas 2D и превращает её в текстуру. Неподвижный текст дёшев, а каждое изменение — новая картинка;
- **стиль** задаёт шрифт, размер, заливку, обводку, тень, выравнивание и переносы. По умолчанию текст чёрный;
- **веб-шрифт** загружается через `Assets` и должен быть загружен **до** создания текстов;
- **`resolution`** — запас детальности текстуры текста для увеличения и экранов высокой плотности;
- **`BitmapText`** собирает надпись из готовых глифов растрового шрифта: смена текста почти бесплатна, но стиль «запечён»;
- **`HTMLText`** рисует HTML с CSS асинхронно и дорого, а для простого выделения слов у `Text` есть `tagStyles`;
- **свой класс надписи** (`Label`) хранит стиль игры в одном месте.

Надписи сейчас расставлены под превью 500 × 600: стоит изменить размер окна, и поле с надписями остаётся там, где было. В следующей главе займёмся интерфейсом: кнопки, растягиваемые панели, адаптивная раскладка под любой экран и библиотека `@pixi/ui`.
