В игре на время нужен таймер. Он меняется постоянно, а в некоторых играх таких чисел на экране десятки: здоровье над каждым врагом, урон, координаты. Для таких надписей есть `BitmapText` — текст из **растрового шрифта**.

## Растровый шрифт

Идея старая, как сами видеоигры. Вместо того чтобы рисовать каждую надпись целиком, один раз рисуем все нужные символы в одну текстуру: «0», «1», «2»… «:». Изображение одного символа называется **глифом**. Надпись «0:59» — это четыре прямоугольника, вырезанные из этой текстуры и поставленные рядом.

Смена текста в `BitmapText` — это перестановка прямоугольников. Ничего не рисуется на canvas и ничего не загружается в видеокарту. А все надписи одним растровым шрифтом используют одну текстуру и рисуются в одном батче.

Цена — гибкость:

- стиль (шрифт, обводка, тень) «запекается» в глифы при создании шрифта. Поменять обводку у одной надписи нельзя, нужен другой растровый шрифт;
- глифы нарисованы под конкретный размер. При другом размере они масштабируются, и сильное увеличение размывает буквы;
- для каждого стиля нужна своя текстура глифов. Для кириллицы, латиницы, цифр и знаков это уже сотни символов.

## Создаём шрифт

Растровый шрифт можно сделать заранее во внешней программе (BMFont, Hiero, AssetPack) и загрузить файлом `.fnt` или `.xml` через `Assets`. А можно сгенерировать прямо в игре из обычного шрифта — именно так мы и сделаем:

```ts main.ts
// Растровый шрифт: все цифры и двоеточие рисуются один раз в общую текстуру
BitmapFont.install({
  name: 'TimerFont',
  style: { fontFamily: FONT_FAMILY, fontSize: 32, fill: 0xffffff, stroke: { color: 0x2c136c, width: 5 } },
  chars: [['0', '9'], ':'],
  resolution: 2,
});
```

- **`name`** — имя, под которым шрифт будет доступен. Его указывают в `fontFamily` у `BitmapText`;
- **`style`** — обычный `TextStyle`. По нему PixiJS рисует глифы на canvas, так же как `Text`;
- **`chars`** — какие символы нарисовать заранее. Диапазон задаётся парой `['0', '9']`, отдельные символы — строкой. Готовые наборы лежат в объекте `BitmapFontManager`: `NUMERIC`, `ALPHA`, `ALPHANUMERIC` (по умолчанию) и `ASCII`. Кириллицы среди них нет, её пришлось бы перечислить самим: `['а', 'я']`, `['А', 'Я']` и отдельно `'ё'` и `'Ё'`, которые в эти диапазоны не входят;
- **`resolution`** — детальность глифов, как у `Text`.

Заметьте: шрифт генерируется из Nunito, поэтому `install` должен идти **после** загрузки веб-шрифта. Ловушка из прошлого шага здесь ещё опаснее: глифы рисуются один раз, и если шрифт не загружен, в них навсегда запечётся запасной шрифт.

## Таймер

Добавьте после счёта:

```ts main.ts
import { Application, Assets, BitmapFont, BitmapText, Sprite, Text, Texture } from 'pixi.js';
```

```ts main.ts
// --- Таймер слева над полем: BitmapText ---
/** Длительность игры в миллисекундах */
const GAME_TIME = 60_000;
/** За сколько миллисекунд до конца таймер начинает мигать */
const WARNING_TIME = 10_000;

// … BitmapFont.install, как выше

const timerText = new BitmapText({ text: formatTime(GAME_TIME), style: { fontFamily: 'TimerFont', fontSize: 28 } });
timerText.anchor.set(0, 0.5);
timerText.position.set(board.x - BOARD_WIDTH / 2, scoreText.y);
app.stage.addChild(timerText);

let remaining = GAME_TIME;
app.ticker.add((ticker) => {
  // Время идёт, только пока поле доступно: на отсчёте и на паузе таймер стоит
  if (board.locked || remaining === 0) return;
  remaining = Math.max(0, remaining - ticker.deltaMS);
  timerText.text = formatTime(remaining);
  // В последние секунды мигаем красным: тонирование умножает цвета глифов, белый становится красным
  const blink = remaining > 0 && remaining < WARNING_TIME && Math.floor(remaining / 250) % 2 === 0;
  timerText.tint = blink ? 0xff5a5a : 0xffffff;
});

/** 59999 → «1:00», 9000 → «0:09». Округляем вверх, как настоящие таймеры */
function formatTime(ms: number) {
  const seconds = Math.ceil(ms / 1000);
  return `${Math.floor(seconds / 60)}:${String(seconds % 60).padStart(2, '0')}`;
}
```

Разберём:

- **`BitmapText`** создаётся так же, как `Text`, но в `fontFamily` — имя растрового шрифта. `fontSize: 28` меньше, чем 32 в шрифте: глифы уменьшатся, и это не страшно. Уменьшение не портит чёткость, а запас `resolution: 2` позволит и немного увеличить;
- **время копится из `deltaMS`** — по правилам главы 8. И раз мы берём время у `app.ticker`, клавиша `3` замедляет и таймер;
- **`board.locked`** — таймер стоит, пока идёт отсчёт и пока включена пауза. Флаг блокировки уже есть, и он означает ровно «сейчас не играем»;
- **мигание** — `tint` из главы 2. Белые буквы, умноженные на красный, становятся красными, а тёмная обводка — почти не меняется. `Math.floor(remaining / 250) % 2` переключается каждые 250 мс: четыре смены в секунду;
- **`Math.ceil`** — таймер показывает «0:01», пока не прошла последняя секунда целиком, и «0:00» ровно в конце. Так ведут себя таймеры в играх и на кухне.

Когда время выходит, таймер останавливается на «0:00», но играть можно дальше. Конец игры и экран результата появятся в главе 11.

## Что получилось

Слева над полем — таймер «1:00». Пока идёт отсчёт, он стоит, а потом начинает убывать. Нажмите паузу: таймер замер. Мы проверили: за две секунды игры таймер ушёл с 0:49 на 0:47, а за две секунды паузы не изменился. На укороченном до 12 секунд таймере проверка увидела все значения от 0:12 до 0:00 и красный цвет в последние секунды.

## Эксперименты

- Поставьте `GAME_TIME = 15_000`, чтобы быстрее увидеть мигание. Верните 60 секунд.
- Напишите в таймер букву: `timerText.text = 'Время 1:00'`. Она появится, хотя её нет в `chars`! В PixiJS v8 растровый шрифт, созданный через `install`, **дорисовывает** недостающие глифы при первом использовании. `chars` — это список того, что нарисовать заранее, а не ограничение. Дорисовка — это та же работа с canvas, которую мы хотели избежать, поэтому все символы, которые будут меняться часто, лучше перечислить сразу.
- Поставьте `fontSize: 64`. Таймер стал вдвое больше и мягче: глифы растянуты из размера 32.

::: deep Под капотом: как BitmapText собирает надпись
`BitmapFont.install` создаёт `DynamicBitmapFont`: он рисует каждый глиф на canvas, укладывает глифы рядами в общую текстуру-страницу и запоминает для каждого символа прямоугольник, смещения и ширину шага. Если глифы не помещаются, начинается следующая страница.

`BitmapText` при смене текста раскладывает строку по этим данным: для каждого символа — прямоугольник с координатами из таблицы, с учётом **кернинга** (поправок расстояния для пар вроде «AV»). Результат — набор четырёхугольников с одной текстурой. Это почти то же самое, что нарисовать несколько спрайтов из атласа, и рендерер объединяет их в батч.

Кстати, `BitmapText` работает и без `install`: если в `fontFamily` указать обычный шрифт, PixiJS сам создаст растровый шрифт для этого стиля. Но для каждого нового сочетания стиля создаётся новая текстура глифов, и после 50 таких шрифтов PixiJS выводит предупреждение с советом установить шрифты заранее.

Третий вариант — шрифты **MSDF** (multi-channel signed distance field). Вместо цвета пикселя в текстуре хранится расстояние до края буквы, а специальный шейдер восстанавливает чёткий край при любом масштабе. Такой шрифт готовят заранее инструментами вроде msdf-bmfont и загружают через `Assets`. Это выбор для игр, где текст сильно масштабируется.
:::
