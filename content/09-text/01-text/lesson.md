Поле ожило, но в игре до сих пор нет ни одной надписи. Игрок не знает, сколько у него очков и сколько осталось времени, а «Комбо!» видно только в консоли. В этой главе займёмся текстом. К её концу над полем будут счёт и таймер, под полем — подсказка, а из каждого совпадения будут взлетать очки «+30».

Сначала о том, что изменилось в коде:

- функция `playCountdown` переехала из `main.ts` в отдельный файл `countdown.ts`. Теперь она принимает родителя и точку, в которой показать цифры. Код внутри тот же, что в главе 8;
- `Board.ts` экспортирует размеры поля без рамки `BOARD_WIDTH` и `BOARD_HEIGHT`. Они нужны, чтобы расставлять надписи вокруг поля.

## Как PixiJS рисует текст

Видеокарта не умеет рисовать буквы. Она умеет рисовать треугольники с текстурами. Поэтому любой текст в PixiJS в итоге превращается в текстуру, и есть три способа это сделать:

| Класс | Как получается текстура | Когда использовать |
|---|---|---|
| `Text` | Браузер рисует строку на скрытом canvas 2D, а canvas становится текстурой | Почти всегда: заголовки, кнопки, счёт |
| `BitmapText` | Все нужные символы заранее нарисованы в одну общую текстуру, надпись собирается из кусочков | Часто меняющиеся числа, много надписей |
| `HTMLText` | Браузер рисует настоящий HTML с CSS, результат становится текстурой | Сложное форматирование |

Начнём с самого простого и самого частого — `Text`. Остальные два разберём в шагах 5 и 6.

## Первая надпись

```ts
const scoreText = new Text({ text: 'Очки: 0', style: { fill: 0xffffff } });
```

- **`text`** — сама строка. Можно передать и число: `Text` превратит его в строку;
- **`style`** — внешний вид: шрифт, размер, цвет и ещё десятки настроек. Их разберём в следующем шаге. Пока зададим только цвет заливки букв `fill`.

`Text` — такой же объект сцены, как `Sprite`: у него есть позиция, масштаб, поворот, прозрачность и **якорь**. Якорь работает так же, как у спрайта: `0.5` — центр надписи. Для текста центральный якорь особенно удобен: надпись «Очки: 0» и надпись «Очки: 1250» разной ширины, но обе останутся по центру.

Поменять надпись можно в любой момент:

```ts
scoreText.text = `Очки: ${score}`;
```

## Откуда брать очки

Очки начисляются за совпадения, а о совпадениях знает только `Board`. Нужен способ сообщить наружу: «в этом раунде каскада нашлись такие совпадения». Сделаем это колбэком, как `onTap` и `onSwipe` у фишки. В `Board.ts` добавьте поле:

```ts Board.ts
  /** Вызывается в каждом раунде каскада, когда найдены совпадения. round — номер раунда, с 1 */
  onMatch?: (matches: Position[][], round: number) => void;
```

И вызовите его в `process`, перед тем как совпадения исчезнут:

```ts Board.ts {3}
    while (matches.length > 0) {
      round++;
      this.onMatch?.(matches, round);
      await this.popMatches(matches);
```

Номер раунда пока не нужен, но пригодится для комбо в последнем шаге главы. В оригинале так же: `Match3` сообщает экрану игры о совпадениях колбэком `onMatch`, а данные в нём — список совпадений и номер раунда `combo`.

## Счёт над полем

Теперь в `main.ts`, после создания поля:

```ts main.ts
import { Application, Assets, Sprite, Text, Texture } from 'pixi.js';
import { Board, BOARD_HEIGHT } from './Board';
```

```ts main.ts
// --- Счёт над полем ---
let score = 0;
const scoreText = new Text({ text: 'Очки: 0', style: { fill: 0xffffff } });
scoreText.anchor.set(0.5);
scoreText.position.set(board.x, board.y - BOARD_HEIGHT / 2 - 38);
app.stage.addChild(scoreText);

board.onMatch = (matches) => {
  // 10 очков за каждую фишку в совпадении
  for (const match of matches) score += match.length * 10;
  scoreText.text = `Очки: ${score}`;
};
```

Позиция считается от поля: `board.y - BOARD_HEIGHT / 2` — верхний край клеток, а ещё 38 пикселей вверх — середина полосы между рамкой поля и краем превью.

## Что получилось

Над полем появилась белая надпись «Очки: 0». Сделайте ход: тройка даёт 30 очков, четвёрка — 40, а каскад добавляет очки в каждом раунде. Мы проверили автоматически: после восьми ходов счёт на экране совпал с очками, посчитанными независимо по тем же совпадениям.

Шрифт пока самый обычный, а надпись выглядит бедно. Это исправим в следующем шаге.

## Эксперименты

- Уберите `style` совсем. Надпись станет **чёрной**, шрифтом Arial размером 26 пикселей. Это стиль по умолчанию, и чёрный цвет на тёмном фоне — частая причина вопроса «почему мой текст не виден?». Верните белый цвет.
- Поставьте `scoreText.anchor.set(0, 0.5)`. Теперь в точке позиции находится левый край надписи, и при росте счёта она растёт вправо. Верните `0.5`.
- Выведите в консоль `scoreText.width` и `scoreText.height`. Размер текста известен сразу после создания, ещё до отрисовки: PixiJS измеряет строку заранее.

::: deep Под капотом: что делает Text
Когда текст или стиль меняется, `Text` помечается как изменённый. Перед ближайшей отрисовкой PixiJS:

1. измеряет строку через canvas 2D: ширину каждой строки, высоту шрифта, отступы для обводки и тени (класс `CanvasTextMetrics`);
2. берёт скрытый canvas нужного размера и рисует на нём текст обычными командами canvas 2D: `fillText`, `strokeText`;
3. превращает canvas в текстуру и загружает её в видеокарту;
4. рисует прямоугольник с этой текстурой, как обычный спрайт.

Отсюда главное свойство `Text`: **неподвижный текст стоит столько же, сколько спрайт**, а изменение текста — это новая картинка и её загрузка в видеокарту. Во что это обходится, замерим в шаге 4.

Интересная деталь: если на экране несколько `Text` с одинаковой строкой и одинаковым стилем, PixiJS делает для них **одну** текстуру и считает, сколько надписей ею пользуются. Текстура освобождается, когда последняя такая надпись изменится или будет уничтожена.
:::
