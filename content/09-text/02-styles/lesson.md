Счёт работает, но выглядит как подпись в отладчике: тонкий белый Arial. В играх текст почти всегда оформлен: крупный округлый шрифт, обводка, тень. Обводка и тень нужны не только для красоты: они отделяют буквы от фона. Белый текст без обводки теряется на светлом фоне, а тёмный — на тёмном.

## Стиль текста

Всё оформление задаётся объектом `style`. Можно передать обычный объект, как мы делали, и `Text` сам создаст из него `TextStyle`. Главные свойства:

| Свойство | Что задаёт | По умолчанию |
|---|---|---|
| `fontFamily` | Шрифт или список шрифтов | `'Arial'` |
| `fontSize` | Размер в пикселях | `26` |
| `fontWeight` | Насыщенность: `'normal'`, `'bold'`, `'100'`…`'900'` | `'normal'` |
| `fill` | Заливка букв: цвет, градиент `FillGradient` или `{ color, alpha }` | чёрный |
| `stroke` | Обводка букв: `{ color, width }` | нет |
| `dropShadow` | Тень: `{ color, alpha, blur, distance, angle }` | нет |
| `align` | Выравнивание строк между собой | `'left'` |
| `wordWrap`, `wordWrapWidth` | Переносить ли строки и по какой ширине | `false`, `100` |
| `lineHeight` | Расстояние между базовыми линиями строк | по размеру шрифта |

Заливка и обводка устроены так же, как у `Graphics` в главе 4: те же цвета, те же градиенты. И та же ловушка: если указать обводку без цвета, `stroke: { width: 5 }`, она будет **белой**.

## Оформляем счёт

Перепишите создание счёта:

```ts main.ts
const scoreText = new Text({
  text: 'Очки: 0',
  style: {
    fontFamily: ['Arial Rounded MT Bold', 'Arial', 'sans-serif'],
    fontSize: 30,
    fill: 0xffffff,
    // Тёмная обводка и мягкая тень отделяют текст от любого фона
    stroke: { color: 0x2c136c, width: 5 },
    dropShadow: { color: 0x000000, alpha: 0.4, blur: 2, distance: 3, angle: Math.PI / 2 },
  },
});
```

- **`fontFamily` списком** — это то же самое, что `font-family` в CSS. Браузер берёт первый шрифт из списка, который есть в системе. Arial Rounded MT Bold — шрифт оригинальной игры. Он есть на macOS, но на Windows и Android его обычно нет, и там вы увидите обычный Arial. Последним стоит `sans-serif` — «любой шрифт без засечек», он есть всегда. Такой шрифт в конце списка называется **запасным**;
- **обводка** рисуется по контуру каждой буквы: половина толщины снаружи, половина внутри. Поэтому толстая обводка «съедает» тонкие буквы. 5 пикселей при размере 30 — разумный предел;
- **тень** — копия текста, сдвинутая на `distance` пикселей в направлении `angle` (в радианах, отсчёт от оси x по часовой стрелке). `Math.PI / 2` — строго вниз. `blur` размывает края тени, а `alpha` делает её полупрозрачной. Незаданные поля тени берутся из значений по умолчанию: чёрная, без размытия, на 5 пикселей под углом 30°.

## Подсказка под полем

Второй текст покажет, как работают переносы. Добавьте после счёта:

```ts main.ts
import { Board, BOARD_HEIGHT, BOARD_WIDTH } from './Board';
```

```ts main.ts
// --- Подсказка под полем ---
const hintText = new Text({
  text: 'Меняйте местами соседние зелья. Три одинаковых в ряд исчезают и приносят очки.',
  style: {
    fontFamily: ['Arial Rounded MT Bold', 'Arial', 'sans-serif'],
    fontSize: 15,
    // Подсказка лежит на светлом фоне, поэтому тёмная
    fill: 0x3b1d70,
    align: 'center',
    // Переносим строки, чтобы подсказка не была шире поля
    wordWrap: true,
    wordWrapWidth: BOARD_WIDTH,
    lineHeight: 20,
  },
});
hintText.anchor.set(0.5);
hintText.position.set(board.x, board.y + BOARD_HEIGHT / 2 + 40);
app.stage.addChild(hintText);
```

- **`wordWrap: true`** и **`wordWrapWidth`** — переносить слова на новую строку, когда строка становится шире 350 пикселей. Переносы идут по пробелам. Слово длиннее всей ширины переносится, только если включить `breakWords: true`. Перенос в нужном месте можно задать и вручную, символом `\n` в строке;
- **`align: 'center'`** — строки выравниваются по центру **друг относительно друга**. Это не то же самое, что якорь. Якорь решает, где весь блок текста стоит относительно позиции, а `align` — как короткая строка располагается внутри блока под длинной. У однострочного текста `align` ни на что не влияет;
- **`lineHeight`** — расстояние между строками. По умолчанию оно зависит от шрифта, а явное значение делает блок предсказуемым.

## Эксперименты

- Поставьте подсказке `align: 'left'`, затем `'right'`. Вторая строка короче первой и сдвигается к краю. А сам блок остаётся по центру поля: его держит якорь.
- Выключите `wordWrap`. Подсказка вытянется в одну строку шире превью и обрежется по краям.
- Замените заливку счёта градиентом из главы 4:

  ```ts
  fill: new FillGradient({
    type: 'linear',
    start: { x: 0, y: 0 },
    end: { x: 0, y: 1 },
    colorStops: [
      { offset: 0, color: '#ffffff' },
      { offset: 1, color: '#ffd27f' },
    ],
  }),
  ```

  Буквы станут белыми сверху и золотыми снизу. Вертикальный градиент применяется к каждой строке текста отдельно. Не забудьте импортировать `FillGradient`.
- Поставьте `dropShadow: true`. Получится тень по умолчанию: чёрная, резкая, на 5 пикселей вправо-вниз.

::: warning
В старых статьях вы встретите `new Text('Очки', { fill: 'white', strokeThickness: 4, dropShadowDistance: 3 })`. Это API v7. В v8 текст создаётся объектом `{ text, style }`, толщина обводки задаётся внутри `stroke: { width }`, а все настройки тени — внутри объекта `dropShadow`. Старый вариант пока работает, но выводит предупреждения об устаревании.
:::

::: deep Под капотом: стиль — отдельный объект
`style` у текста — это экземпляр класса `TextStyle`. Если передать обычный объект, каждый `Text` создаст свой `TextStyle`. А если создать стиль заранее и передать **один и тот же** экземпляр нескольким надписям, они будут его разделять:

```ts
const style = new TextStyle({ fontSize: 30, fill: 0xffffff });
const a = new Text({ text: 'A', style });
const b = new Text({ text: 'B', style });
style.fill = 0xff0000; // обе надписи станут красными
```

Это работает, потому что `TextStyle` сообщает о каждом изменении событием `update`, а все тексты, которые его используют, на это событие подписаны. Каждое изменение свойства стиля — это перерисовка текстуры у всех таких надписей, так что менять стиль каждый кадр не стоит.
:::
