Кто-то играет в наушниках в метро и хочет только эффекты. Кому-то музыка нравится, а «бульки» раздражают. Звук, который нельзя настроить, рано или поздно выключают целиком — вместе с игрой. Поэтому почти в каждой игре в настройках есть громкость, и обычно не одна.

Сделаем два слайдера: **музыка** и **звуки**. Для этого и нужны были отдельные `bgm` и `sfx`.

## Три уровня громкости

Вспомните врезку из шага 2: громкость, которую слышит игрок, — произведение трёх множителей:

```
громкость библиотеки × громкость звука × громкость копии
 sound.volumeAll         Sound.volume      volume в PlayOptions
```

Какой из них отдать слайдерам?

- **Копия** — не подходит: её громкость задаётся при `play`, а у музыки копия живёт минутами. Двигаешь слайдер — а играющая музыка не меняется. К тому же громкость копий — это микширование: в игре музыка на 0,5, звуки хода на 0,5. Его слайдер трогать не должен.
- **Библиотека** — это общая громкость всего сразу. Отдельно музыку и эффекты ею не настроить.
- **Звук** — то, что нужно для музыки. Именно `Sound.volume` анимирует кроссфейд в `BGM`, и сеттер сразу меняет громкость играющих копий.

С эффектами сложнее: их звуков много, и класть громкость в каждый `Sound` неудобно. Поэтому `SFX` умножает свою громкость на громкость копии при каждом `play` — это мы заложили ещё в шаге 2.

## Громкость в BGM и SFX

Добавьте методы, которые меняют громкость. В `BGM`:

```ts audio.ts
  /** Меняет громкость музыки, в том числе той, что уже играет */
  setVolume(value: number) {
    this.volume = value;
    if (!this.current) return;
    // Если музыка ещё нарастает, твин перезаписал бы новую громкость: останавливаем его
    gsap.killTweensOf(this.current);
    this.current.volume = value;
  }
```

В `SFX`:

```ts audio.ts
  /** Меняет громкость эффектов. Звуки, которые уже звучат, доиграют с прежней громкостью */
  setVolume(value: number) {
    this.volume = value;
  }
```

У эффектов громкость новая только для **новых** копий: старые уже получили свою при `play`. Эффекты короткие, и этого никто не заметит.

## Настройки вместо скорости

Слайдер скорости игры из главы 10 был учебным: он помог разобраться с `Slider` и замедлением тикера, но игроку он не нужен, и в оригинале его нет. Его место займут громкости. В `userSettings.ts` замените `speed`:

```ts userSettings.ts
export const userSettings = {
  /** Громкость музыки: от 0 до 1 */
  music: 1,
  /** Громкость звуковых эффектов: от 0 до 1 */
  sfx: 1,
  /** Показывать ли подсказку под полем */
  hint: true,
};
```

В попапе настроек слайдеров теперь два, и одинаковый код создания слайдера вынесем в функцию:

```ts SettingsPopup.ts
/** Слайдер громкости: от 0 до 100 % с шагом 5 */
function createVolumeSlider(volume: number) {
  return new Slider({
    bg: new Graphics().roundRect(0, 0, 240, 20, 10).fill(0xcf4b00),
    fill: new Graphics().roundRect(0, 0, 240, 20, 10).fill(0xff8221),
    slider: new Graphics().circle(0, 0, 16).fill(0xcf4b00).circle(0, 0, 12).fill(0xffd579),
    min: 0,
    max: 100,
    step: 5,
    // Попап создаётся заново при каждом открытии и начинает с текущей настройки
    value: Math.round(volume * 100),
  });
}
```

Вместо блока слайдера скорости в конструкторе:

```ts SettingsPopup.ts
    const musicLabel = new Label(`Музыка: ${Math.round(userSettings.music * 100)}%`, { fontSize: 20 });
    musicLabel.y = -110;
    const music = createVolumeSlider(userSettings.music);
    music.label = 'musicSlider';
    music.position.set(-120, -85);
    music.onUpdate.connect((value) => {
      musicLabel.text = `Музыка: ${value}%`;
      userSettings.music = value / 100;
      bgm.setVolume(userSettings.music);
    });
    this.panel.addChild(musicLabel, music);

    const sfxLabel = new Label(`Звуки: ${Math.round(userSettings.sfx * 100)}%`, { fontSize: 20 });
    sfxLabel.y = -40;
    const effects = createVolumeSlider(userSettings.sfx);
    effects.label = 'sfxSlider';
    effects.position.set(-120, -15);
    effects.onUpdate.connect((value) => {
      sfxLabel.text = `Звуки: ${value}%`;
      userSettings.sfx = value / 100;
      sfx.setVolume(userSettings.sfx);
    });
    // Слайдер отпустили: пусть игрок услышит, как теперь звучат эффекты
    effects.onChange.connect(() => sfx.play('common/sfx-press.wav'));
    this.panel.addChild(sfxLabel, effects);
```

Громкость музыки игрок слышит сразу, пока тянет слайдер: музыка-то играет. А эффектов в попапе не слышно, и слайдер «Звуки» двигался бы вслепую. Поэтому, когда его **отпускают**, звучит короткий звук нажатия с новой громкостью. В главе 10 мы пользовались только сигналом `onUpdate` — он приходит на каждое движение. **`onChange`** приходит один раз, когда слайдер отпустили. Играть звук на каждое движение было бы слишком: при перетаскивании это десятки звуков.

Осталось подвинуть остальное: панель выше — `createPanel(320, 410)`, заголовок на `y = -160`, флажок подсказки на `(-70, 40)`, кнопка «Готово» на `y = 135`. Импорт `app` больше не нужен, вместо него — `bgm` и `sfx` из `./audio`.

## Что получилось

Откройте настройки во время игры. Тяните «Музыка» влево — музыка тише прямо под рукой. Отпустите «Звуки» на середине — пробный звук сыграет с громкостью 0,5. Закройте попап и сделайте ход: эффекты тише, а музыка — как настроили.

Проверка подтвердила числа: после того как оба слайдера сдвинуты на 50 %, громкость звука `bgm-game` — 0,5, пробный звук сыгран с громкостью 0,5, а следующий ход без совпадения — с громкостью 0,25: 0,5 (слайдер) × 0,5 (`QUIET`).

## Эксперименты

- Сдвиньте «Музыка» в 0 и сыграйте до результата. Кроссфейд на экране результата поднимет новую музыку до громкости `bgm` — до нуля. Тишина сохраняется между экранами, как и должно быть.
- Добавьте третий слайдер «Общая» с `sound.volumeAll = value / 100`. Он делает тише всё сразу, включая уже звучащие эффекты: это громкость всей библиотеки. Так устроен слайдер Master в оригинале.

## Связь с оригиналом

В оригинале три громкости: общая (`setMasterVolume` — `sound.volumeAll`, а при нуле ещё и `sound.muteAll()`), музыка (`bgm.setVolume`) и эффекты (`sfx.setVolume`). Они меняются в `SettingsPopup` тремя `VolumeSlider`. Наш `bgm.setVolume` отличается одной строкой: оригинал не останавливает твин кроссфейда, и если двинуть слайдер в первую секунду после смены музыки, твин вернёт громкость к старому значению.

::: deep Под капотом: почему половина слайдера — это не «вдвое тише»
Слайдер на 50 % умножает амплитуду на 0,5. Это −6 дБ. А «вдвое тише» на слух — примерно −10 дБ, то есть амплитуда около 0,3. Поэтому линейный слайдер громкости ощущается неравномерно: на правой половине громкость на слух меняется мало, а основное изменение сжато у левого края.

Звуковые программы и многие игры переводят положение слайдера в громкость нелинейно: например, возводят в квадрат или в куб (`volume = value ** 2`), или задают громкость в децибелах (положение слайдера → от −60 до 0 дБ → `10 ** (dB / 20)`). Попробуйте `bgm.setVolume((value / 100) ** 2)` и сравните, как ощущается слайдер. Хранить в настройках при этом лучше само положение слайдера, а пересчитывать при применении.
:::
