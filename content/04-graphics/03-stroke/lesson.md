Подложка сливается с фоном. Добавим ей тонкую золотистую рамку: так поле станет похоже на доску, как в оригинале.

## `stroke` — обводка фигуры

`fill` закрашивает фигуру изнутри, а **`stroke`** рисует линию по её контуру. Его вызывают в той же цепочке после фигуры, причём можно сразу после `fill`: тогда одна и та же фигура будет и залита, и обведена.

```ts main.ts {4}
const background = new Graphics()
  .roundRect(-BOARD_WIDTH / 2 - PADDING, -BOARD_HEIGHT / 2 - PADDING, BOARD_WIDTH + PADDING * 2, BOARD_HEIGHT + PADDING * 2, 16)
  .fill({ color: 0x000000, alpha: 0.3 })
  .stroke({ width: 3, color: 0xffd27f, alignment: 1 });
```

Основные параметры обводки:

| Параметр | Что задаёт | По умолчанию |
|---|---|---|
| `width` | Толщина линии в пикселях | `1` |
| `color`, `alpha` | Цвет и прозрачность | белый, `1` |
| `alignment` | Где линия относительно контура | `0.5` |
| `cap` | Концы незамкнутых линий: `'butt'`, `'round'`, `'square'` | `'butt'` |
| `join` | Углы: `'miter'`, `'round'`, `'bevel'` | `'miter'` |

## `alignment` — внутри, снаружи, посередине

У линии толщиной 3 пикселя есть вопрос: где она проходит относительно контура?

- `alignment: 0.5` — **посередине**: полтора пикселя внутри фигуры, полтора снаружи;
- `alignment: 1` — **внутри**: вся линия внутри фигуры, размер не меняется;
- `alignment: 0` — **снаружи**: фигура визуально становится больше на толщину линии.

Мы ставим `1`: тогда рамка не выходит за пределы подложки, и её размер остаётся ровно таким, как мы посчитали.

::: warning
Значения легко перепутать: `1` — это **внутри**, а `0` — **снаружи**. Если рамка внезапно «вылезла» за край или наложилась на соседний элемент, первым делом проверьте `alignment`.
:::

## Что получилось

Вокруг поля появилась тонкая золотая рамка со скруглёнными углами.

Поэкспериментируйте:

- `width: 12` и по очереди `alignment: 0`, `0.5` и `1`. Посмотрите, где оказывается рамка относительно крайних фишек;
- уберите `.fill(...)`: останется только рамка, подложка станет прозрачной;
- поменяйте порядок: сначала `.stroke(...)`, потом `.fill(...)`. Заливка ляжет **поверх** внутренней половины обводки: в одной цепочке всё рисуется по порядку.

::: deep Под капотом: почему толстые линии — это сложно
Для видеокарты линия — это не линия, а **полоса из треугольников**. PixiJS вычисляет для каждого отрезка контура два параллельных края на расстоянии половины толщины, соединяет их треугольниками, а в углах достраивает соединения по правилу `join`. Для `'round'` углы и концы аппроксимируются дугами из множества мелких треугольников.

Отсюда практический вывод: обводка дороже заливки, особенно с `join: 'round'` и при постоянной перерисовке. Для неподвижной рамки это неважно: треугольники посчитаются один раз.

Отдельный случай — **тонкие линии в 1 пиксель**. При дробных координатах они размываются на два пикселя. Для чётких линий есть параметр `pixelLine: true`: PixiJS рисует такую линию особым способом, всегда ровно в один физический пиксель, независимо от масштаба.
:::
