Готовые фигуры покрывают многое, но не всё. Иногда нужно нарисовать что-то своё: линии, стрелку, волну, контур котла. Для этого у `Graphics` есть **пути**: вы ведёте воображаемое перо от точки к точке, а потом обводите или заливаете то, что получилось. Нарисуем тонкие линии между клетками поля.

## Перо и путь

Путь строится командами, которые двигают «перо»:

| Метод | Что делает |
|---|---|
| `moveTo(x, y)` | Поднимает перо и переносит в точку, ничего не рисуя |
| `lineTo(x, y)` | Ведёт прямую линию от текущей точки до `(x, y)` |
| `arc(cx, cy, r, start, end)` | Дуга окружности с центром `(cx, cy)`, углы в радианах |
| `quadraticCurveTo(cpx, cpy, x, y)` | Плавная кривая с одной контрольной точкой |
| `bezierCurveTo(cp1x, cp1y, cp2x, cp2y, x, y)` | Кривая Безье с двумя контрольными точками |
| `closePath()` | Соединяет текущую точку с началом фигуры |

Если вы рисовали в Canvas 2D, всё это знакомо: в PixiJS v8 эти методы повторяют API браузерного Canvas.

Важная деталь: **путь может состоять из многих отдельных кусков**. Каждый `moveTo` начинает новый кусок, но всё это остаётся одним путём, и один вызов `stroke()` в конце обведёт его целиком.

## Линии между клетками

Внутренние вертикальные линии проходят между столбцами, их `COLUMNS − 1`, то есть 6. Горизонтальных — `ROWS − 1`, то есть 8. Для каждой линии — `moveTo` в начало и `lineTo` в конец, а в конце одна обводка на всё:

```ts main.ts
// Линии между клетками: один путь из множества отрезков, одна обводка в конце
const lines = new Graphics();
lines.label = 'lines';
for (let column = 1; column < COLUMNS; column++) {
  const x = -BOARD_WIDTH / 2 + column * TILE_SIZE;
  lines.moveTo(x, -BOARD_HEIGHT / 2).lineTo(x, BOARD_HEIGHT / 2);
}
for (let row = 1; row < ROWS; row++) {
  const y = -BOARD_HEIGHT / 2 + row * TILE_SIZE;
  lines.moveTo(-BOARD_WIDTH / 2, y).lineTo(BOARD_WIDTH / 2, y);
}
lines.stroke({ width: 1, color: 0xffffff, alpha: 0.12 });
board.addChildAt(lines, 1);
```

`addChildAt(lines, 1)` кладёт линии сразу над подложкой (индекс 0), но под фишками.

:::

## Что получилось

Поле расчерчено тонкой еле заметной сеткой. Она подсказывает игроку, где границы клеток, но не спорит с яркими зельями.

Поэкспериментируйте:

- у горизонтальных линий замените `moveTo` на `lineTo`: перо больше не поднимается, каждая линия начинается там, где закончилась предыдущая, и сетка превратится в зигзаг. Забытый `moveTo` — главная ошибка при работе с путями;
- поставьте `alpha: 1` и `width: 3`, чтобы рассмотреть сетку.

## Вырезы: `cut`

Иногда в фигуре нужна **дыра**: кольцо, рамка, окошко. Для этого нарисуйте внешнюю фигуру с заливкой, потом внутреннюю и вызовите `cut()`. Внутренняя фигура будет вычтена из предыдущей:

```ts
const ring = new Graphics()
  .circle(0, 0, 40)
  .fill(0xffd27f)
  .circle(0, 0, 25)
  .cut();
```

Получится кольцо: сквозь дыру будет видно всё, что лежит ниже. Попробуйте добавить такое кольцо на сцену и поставить его поверх поля, чтобы убедиться, что дыра действительно прозрачная.

::: warning
Вырез должен целиком лежать **внутри** фигуры, из которой вырезается. Если он выходит за её края, `cut` сработает неправильно.
:::

::: deep Под капотом: SVG
Если фигура сложная, её проще нарисовать в векторном редакторе, чем описывать координатами. `Graphics` умеет читать SVG:

```ts
const icon = new Graphics().svg('<svg><path d="M 0 0 L 40 0 L 20 30 Z" fill="#ffd27f"/></svg>');
```

PixiJS разбирает SVG и превращает его в те же команды `moveTo`, `lineTo`, `bezierCurveTo`, `fill` и `stroke`. Поддерживается основное подмножество SVG: пути, фигуры, заливки и обводки. Фильтры, маски и текст внутри SVG — нет.
:::
