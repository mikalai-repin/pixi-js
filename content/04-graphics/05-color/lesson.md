Чёрная полупрозрачная подложка — практичное, но скучное решение. В оригинальной игре фон поля — тёмно-фиолетовый с переходом. Сделаем подложку с **градиентом**: сверху светлее, снизу темнее.

## Чем можно залить фигуру

`fill` и `stroke` принимают не только цвет:

| Что передать | Пример | Результат |
|---|---|---|
| Цвет | `.fill(0xff0000)`, `.fill('#ff0000')` | Сплошной цвет |
| Цвет с прозрачностью | `.fill({ color: 0xff0000, alpha: 0.5 })` | Полупрозрачный цвет |
| Градиент | `.fill(gradient)` | Плавный переход цветов |
| Текстура | `.fill({ texture, color })` | Картинка внутри фигуры |

Все форматы цвета из главы 1 работают и здесь. А если с цветом нужно что-то посчитать — осветлить, смешать, перевести в другой формат, — есть класс **`Color`**:

```ts
const gold = new Color('#ffd27f');
gold.toHex();      // '#ffd27f'
gold.toNumber();   // 16765567 — то же, что 0xffd27f
gold.toRgbArray(); // ≈ [1, 0.82, 0.5] — компоненты от 0 до 1
```

## Линейный градиент

**Градиент** (`FillGradient`) — плавный переход между несколькими цветами. Он задаётся **точками остановки** (color stops): в какой доле пути какой цвет. Между ними PixiJS сам вычисляет промежуточные оттенки.

```ts main.ts
const backgroundGradient = new FillGradient({
  type: 'linear',
  start: { x: 0, y: 0 },
  end: { x: 0, y: 1 },
  colorStops: [
    { offset: 0, color: '#4a2a7a' },
    { offset: 1, color: '#160a2e' },
  ],
});
```

- `start` и `end` — откуда и куда идёт переход. Координаты задаются **в долях фигуры**: `(0, 0)` — её левый верхний угол, `(0, 1)` — левый нижний. Значит, переход идёт сверху вниз.
- `colorStops` — точки остановки: `offset: 0` — цвет в начале, `offset: 1` — в конце. Точек может быть больше двух: например, `offset: 0.5` задаст цвет посередине.

Доли удобны так же, как у якоря: градиент растянется на фигуру любого размера.

Залейте подложку градиентом вместо чёрного цвета:

```ts main.ts {3}
const background = new Graphics()
  .roundRect(-BOARD_WIDTH / 2 - PADDING, -BOARD_HEIGHT / 2 - PADDING, BOARD_WIDTH + PADDING * 2, BOARD_HEIGHT + PADDING * 2, 16)
  .fill(backgroundGradient)
  .stroke({ width: 3, color: 0xffd27f, alignment: 1 });
```

Не забудьте импортировать `FillGradient`.

## Что получилось

Подложка переливается от светло-фиолетового вверху к почти чёрному внизу. Фишки на ней смотрятся объёмнее, а поле больше похоже на оригинал.

Поэкспериментируйте:

- поменяйте `end` на `{ x: 1, y: 1 }`: переход пойдёт по диагонали;
- добавьте третью точку `{ offset: 0.5, color: '#ff6b9d' }`;
- попробуйте радиальный градиент, расходящийся из центра:

```ts
const glow = new FillGradient({
  type: 'radial',
  center: { x: 0.5, y: 0.5 },
  innerRadius: 0,
  outerCenter: { x: 0.5, y: 0.5 },
  outerRadius: 0.5,
  colorStops: [
    { offset: 0, color: '#4a2a7a' },
    { offset: 1, color: '#160a2e' },
  ],
});
```

На прямоугольной подложке радиальный градиент получится не круглым, а **эллиптическим**: доли считаются отдельно по ширине и по высоте фигуры, поэтому на вытянутой фигуре «круг» вытягивается вместе с ней. Наша подложка выше, чем шире, и эллипс получится вертикальным.

::: deep Под капотом: градиент — это текстура
Видеокарта не умеет рисовать градиенты напрямую. PixiJS рисует переход цветов в маленькую текстуру, обычно полоску в 256 пикселей, и натягивает её на фигуру, как картинку. Поэтому градиентная заливка стоит почти столько же, сколько заливка текстурой, и её можно спокойно использовать.

Из этого же следует, что `fill` умеет заливать **любой** текстурой: `.fill({ texture: Texture.from('/assets/preload/background.png') })` заполнит фигуру картинкой. А если указать и `texture`, и `color`, текстура будет тонирована этим цветом, как спрайт через `tint`.
:::
