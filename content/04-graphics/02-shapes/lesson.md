Прямоугольник с острыми углами смотрится грубо. В оригинальной игре почти все панели скруглённые. У `Graphics` есть набор готовых фигур, и скругление — одна из них.

## Набор фигур

Все фигуры рисуются в локальных координатах `Graphics`. У большинства первые два параметра — **центр** фигуры, а у прямоугольников — **левый верхний угол**:

| Метод | Что рисует |
|---|---|
| `rect(x, y, w, h)` | Прямоугольник, `(x, y)` — левый верхний угол |
| `roundRect(x, y, w, h, radius)` | Прямоугольник со скруглёнными углами |
| `chamferRect(x, y, w, h, chamfer)` | Прямоугольник со срезанными углами |
| `circle(x, y, radius)` | Круг, `(x, y)` — центр |
| `ellipse(x, y, halfWidth, halfHeight)` | Эллипс, задаются полуоси |
| `poly([x1, y1, x2, y2, …])` | Многоугольник по точкам |
| `regularPoly(x, y, radius, sides)` | Правильный многоугольник: треугольник, шестиугольник… |
| `star(x, y, points, radius, innerRadius?)` | Звезда |

## Скругляем подложку

Замените `rect` на `roundRect` с радиусом 16. Последний параметр — радиус скругления углов в пикселях:

```ts main.ts {2}
const background = new Graphics()
  .roundRect(-BOARD_WIDTH / 2 - PADDING, -BOARD_HEIGHT / 2 - PADDING, BOARD_WIDTH + PADDING * 2, BOARD_HEIGHT + PADDING * 2, 16)
  .fill({ color: 0x000000, alpha: 0.3 });
```

::: task
Скруглите углы подложки радиусом 16.
:::

## Что получилось

Подложка стала мягче, с закруглёнными углами.

## Песочница фигур

Чтобы почувствовать остальные фигуры, добавьте временно в конец файла этот код. Он рисует фигуры в левом верхнем углу, поверх всего:

```ts
const shapes = new Graphics()
  .circle(40, 40, 25).fill(0xff6b6b)
  .ellipse(110, 40, 35, 20).fill(0xffd27f)
  .regularPoly(180, 40, 25, 6).fill(0x51cf8f)
  .star(250, 40, 5, 28, 12).fill(0xffe066)
  .poly([300, 65, 325, 15, 350, 65]).fill(0x74c0fc)
  .chamferRect(370, 15, 60, 50, 12).fill(0xb197fc);
app.stage.addChild(shapes);
```

Шесть фигур в одном `Graphics`, у каждой своя заливка. Поиграйте с параметрами:

- у `star` поменяйте число лучей и внутренний радиус. Если внутренний радиус равен внешнему, звезда станет правильным многоугольником, причём с удвоенным числом вершин: у пятиконечной звезды их десять;
- у `roundRect` подложки поставьте радиус `200`: PixiJS не даст радиусу стать больше половины меньшей стороны, и подложка превратится в «таблетку».

После экспериментов удалите песочницу.

::: tip
Последний параметр `star`, `regularPoly` и некоторых других фигур — поворот в радианах. Например, `regularPoly(0, 0, 25, 3, Math.PI)` нарисует треугольник вершиной вниз.
:::

::: deep Под капотом: из чего на самом деле состоит круг
Видеокарта не умеет рисовать круги. Она рисует только треугольники. Поэтому PixiJS превращает круг в многоугольник с большим числом сторон, а многоугольник разбивает на треугольники. Этот процесс называется **триангуляцией**.

Число сторон PixiJS подбирает сам в зависимости от радиуса: маленькому кругу хватает пары десятков, большому нужно больше, иначе станут видны грани. Для сложных многоугольников (вогнутых, с дырами) используется алгоритм **earcut**, тот самый, который в PixiJS подключён как зависимость.

Треугольники вычисляются один раз и кэшируются в контексте `Graphics`. Именно поэтому неподвижная графика дешёвая, а постоянно перерисовываемая — нет. К этому вернёмся в шаге 6.
:::
