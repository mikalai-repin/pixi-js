Всё, что мы рисовали до сих пор, неподвижно: нарисовали один раз и забыли. Но иногда фигура должна меняться: полоска здоровья уменьшается, кольцо таймера тает, рамка вокруг выбранной фишки пульсирует. Сделаем такую рамку и заодно разберёмся, во что обходится перерисовка.

## `clear()` и рисование заново

У `Graphics` нет способа «поменять радиус у уже нарисованного круга». Инструкции можно только **стереть** методом `clear()` и записать заново. Поэтому анимированная фигура выглядит так: каждый кадр `clear()`, затем снова фигура и заливка с новыми параметрами.

```ts main.ts
// Рамка выбора: перерисовывается каждый кадр с пульсирующей толщиной
const selection = new Graphics();
selection.label = 'selection';
selection.position.copyFrom(selected.position);
board.addChild(selection);

const SELECTION_SIZE = TILE_SIZE * 1.3 + 6;
let time = 0;
app.ticker.add((ticker) => {
  time += ticker.deltaMS / 1000;
  const pulse = (Math.sin(time * 5) + 1) / 2; // от 0 до 1
  selection
    .clear()
    .roundRect(-SELECTION_SIZE / 2, -SELECTION_SIZE / 2, SELECTION_SIZE, SELECTION_SIZE, 12)
    .stroke({ width: 2 + pulse * 3, color: 0xffffff, alpha: 0.4 + pulse * 0.6 });
});
```

Разберём:

- **рамка рисуется вокруг `(0, 0)`**, а на место ставится через `position`. Это тот же приём, что с якорем в центре: фигуру удобно рисовать относительно её центра, а двигать целиком;
- **размер** — фишка увеличена в 1,3 раза, и ещё 6 пикселей запаса, чтобы рамка не налезала на картинку;
- **`ticker.deltaMS`** — сколько миллисекунд прошло с прошлого кадра. Делим на 1000 и получаем секунды, а `time` — это время с запуска в секундах;
- **`pulse`** — синус, перенесённый из диапазона от −1 до 1 в диапазон от 0 до 1. От него зависят толщина (от 2 до 5 пикселей) и прозрачность (от 0.4 до 1).

Добавьте над выбранной фишкой пульсирующую рамку выбора.

## Что получилось

Вокруг центральной фишки пульсирует белая рамка: то тоньше и прозрачнее, то толще и ярче. Примерно раз в 1,25 секунды: синус проходит полный период за `2π / 5 ≈ 1,26` секунды.

## Сколько это стоит

Неподвижный `Graphics` дешёвый: его треугольники вычислены один раз. А наша рамка **каждый кадр**:

1. стирает инструкции;
2. записывает новые;
3. заново вычисляет треугольники обводки со скруглёнными углами;
4. отправляет новые данные на видеокарту.

Для одной рамки это незаметно. Для сотни анимированных фигур — уже ощутимо. Поэтому есть правило: **если анимацию можно сделать трансформацией или прозрачностью, делайте её так**. Изменение `scale`, `rotation` или `alpha` вообще не трогает треугольники, оно меняет только матрицу и цвет.

Нашу рамку можно было сделать почти так же без перерисовки: нарисовать один раз, а в тикере менять `alpha` и `scale`:

```ts
selection
  .roundRect(-SELECTION_SIZE / 2, -SELECTION_SIZE / 2, SELECTION_SIZE, SELECTION_SIZE, 12)
  .stroke({ width: 3, color: 0xffffff });

app.ticker.add((ticker) => {
  time += ticker.deltaMS / 1000;
  const pulse = (Math.sin(time * 5) + 1) / 2;
  selection.alpha = 0.4 + pulse * 0.6;
  selection.scale.set(1 + pulse * 0.05);
});
```

Попробуйте этот вариант. Разница видна: при масштабировании вместе с рамкой растёт и толщина линии, а при перерисовке толщина меняется независимо от размера. Если такой эффект нужен, перерисовка оправдана. Если нет — выбирайте трансформацию.

::: tip
Перерисовка нужна, когда меняется **форма**: дуга таймера становится короче, полоска заполняется, график строится по новым данным. Такие фигуры обычно простые и их немного, так что `clear()` каждый кадр для них — нормальная практика. В практикуме этой главы мы нарисуем как раз такое кольцо таймера.
:::
