Кнопка «Играть» огромная: 301 × 112 пикселей, ровно как её картинка. А если нужна кнопка поуже? Или панель под заголовок и кнопку, размер которой зависит от содержимого? Картинку можно растянуть через `width` и `height`, но посмотрите, что при этом происходит.

## Почему нельзя просто растянуть

Сожмём спрайт кнопки до 240 × 100:

```ts
const squeezed = new Sprite(Texture.from('button-large'));
squeezed.width = 240;
squeezed.height = 100;
```

Скругления углов стали эллипсами, а бортик снизу — тоньше. Масштаб сжимает **всю** картинку одинаково, вместе с углами и рамкой. Для интерфейса это плохо: у кнопок разного размера должны быть одинаковые углы и одинаковый бортик, иначе они выглядят как разные кнопки.

## Девять зон

Решение придумали давно, оно называется **девятизонным масштабированием** (nine-slice). Картинку мысленно разрезают двумя вертикальными и двумя горизонтальными линиями на девять частей:

```
┌──────┬─────────────┬──────┐
│ угол │  верх  ↔    │ угол │
├──────┼─────────────┼──────┤
│ лево │   центр     │ право│
│  ↕   │    ↔ ↕      │  ↕   │
├──────┼─────────────┼──────┤
│ угол │  низ   ↔    │ угол │
└──────┴─────────────┴──────┘
```

- **углы** не растягиваются никогда;
- **верх и низ** растягиваются только по ширине;
- **лево и право** — только по высоте;
- **центр** — в обе стороны.

Если в углах — скругления, а по краям — рамка постоянной толщины, картинку можно сделать любого размера без искажений. Положение линий задают четыре числа: ширина левой и правой полос и высота верхней и нижней, в пикселях исходной картинки.

В PixiJS это класс `NineSliceSprite`:

```ts
const background = new NineSliceSprite({
  texture: Texture.from('button-large'),
  leftWidth: 36,
  topHeight: 42,
  rightWidth: 36,
  bottomHeight: 52,
  width: 240,
  height: 100,
  anchor: 0.5,
});
```

Как и у `TilingSprite` из главы 8, `width` и `height` у `NineSliceSprite` — это **размер области**, а не масштаб: `scale` остаётся равным 1. Числа краёв взяты из оригинальной игры: у кнопки нижняя полоса выше верхней, потому что внизу бортик.

## Стартовая панель

Сделаем панель, в которой будут название игры, подзаголовок и кнопка. В атласе есть картинка `rounded-rectangle` 366 × 189: белый прямоугольник со скруглёнными углами. Белый — потому что его удобно тонировать в любой цвет. Добавьте перед кнопкой:

```ts main.ts
// --- Стартовая панель: растягиваемая картинка со скруглёнными углами ---
const startPanel = new Container();
startPanel.label = 'startPanel';
startPanel.position.copyFrom(board.position);
app.stage.addChild(startPanel);

/** Углы картинки rounded-rectangle: эти 34 пикселя с каждого края не растягиваются */
const PANEL_SLICES = { leftWidth: 34, topHeight: 34, rightWidth: 34, bottomHeight: 34 };
const panelTexture = Texture.from('rounded-rectangle');
const panelShadow = new NineSliceSprite({ texture: panelTexture, ...PANEL_SLICES, width: 330, height: 300, anchor: 0.5, tint: 0x0a0025 });
panelShadow.y = 14;
const panelBox = new NineSliceSprite({ texture: panelTexture, ...PANEL_SLICES, width: 330, height: 300, anchor: 0.5, tint: 0x2c136c });
const title = new Label('Puzzling Potions', { fontSize: 36, fill: 0xffd27f });
title.y = -95;
const subtitle = new Label('Собери три зелья в ряд!', { fontSize: 20 });
subtitle.y = -45;
startPanel.addChild(panelShadow, panelBox, title, subtitle);
```

- **тень** — та же картинка, тонированная почти в чёрный и сдвинутая на 14 пикселей вниз. Её добавляем первой, поэтому она рисуется под панелью. Так сделан `RoundedBox` в оригинале;
- **`tint`** у `NineSliceSprite` работает так же, как у спрайта;
- **`...PANEL_SLICES`** — четыре края в одном объекте, чтобы не повторять их дважды.

Теперь кнопка. Она переезжает внутрь панели, а её фон становится `NineSliceSprite` размером 240 × 100:

```ts main.ts {1,4,6-16}
playButton.y = 60;
playButton.eventMode = 'static';
playButton.cursor = 'pointer';
startPanel.addChild(playButton);

// Кнопка уже текстуры, но скругления и бортик не искажаются
const playBackground = new NineSliceSprite({
  texture: playTextures.default,
  leftWidth: 36,
  topHeight: 42,
  rightWidth: 36,
  bottomHeight: 52,
  width: 240,
  height: 100,
  anchor: 0.5,
});
```

Строку `playButton.position.copyFrom(board.position)` удалите: позицию кнопки теперь задаёт панель. Смена текстуры в `updatePlayButton` работает без изменений: у `NineSliceSprite` тоже есть свойство `texture`.

И уничтожать после нажатия нужно всю панель вместе с кнопкой:

```ts main.ts
startPanel.destroy({ children: true });
```

Не забудьте импортировать `NineSliceSprite`.

## Что получилось

Над полем — тёмно-фиолетовая панель с тенью, золотым названием Puzzling Potions и белым подзаголовком. Кнопка стала меньше, но её углы такие же круглые, а бортик такой же толщины, как у большой. Мы проверили: фон кнопки — `NineSliceSprite` размером 240 × 100 во всех трёх состояниях.

## Эксперименты

- Поменяйте размеры панели: `width: 250, height: 400`. Панель вытянулась вверх, а углы остались прежними.
- Поставьте кнопке `leftWidth: 5, topHeight: 5, rightWidth: 5, bottomHeight: 5`. Скругления и бортик снова искажаются: теперь они попали в растягиваемые полосы. Края нужно задавать так, чтобы всё «нерастягиваемое» оказалось в углах и на краях.
- Сделайте кнопку уже краёв: `width: 60`. Сумма левого и правого края — 72, больше ширины. PixiJS не рисует перекрывающиеся углы, а пропорционально уменьшает края, и кнопка превращается в таблетку.
- Не передавайте края совсем. По умолчанию каждый край — 10 пикселей, если в атласе для кадра не записаны свои границы (поле `borders` в JSON атласа).

::: deep Под капотом: девять прямоугольников, одна текстура
`NineSliceSprite` — это меш (сетка треугольников) из 4 × 4 вершин, то есть девяти прямоугольников. Текстурные координаты вершин не меняются: каждая вершина всегда берёт одну и ту же точку картинки. А положения вершин пересчитываются при смене размера: крайние ряды стоят на расстоянии `leftWidth`, `rightWidth`, `topHeight`, `bottomHeight` от краёв, а средние растягиваются на всё остальное. Видеокарта сама растягивает картинку внутри каждого прямоугольника.

Поэтому `NineSliceSprite` такой же дешёвый, как обычный спрайт: одна текстура, 18 треугольников, и он попадает в общий батч. Повёрнутые и обрезанные кадры атласа он тоже понимает: наша кнопка в атласе повёрнута на 90°, а на экране выглядит правильно.
:::
