Игра подстраивается под размер окна, но раскладка пока простая: всё стоит вокруг центра поля. На широком мониторе получается маленький островок посреди пустоты: поле 370 × 470 на экране 1280 × 800, счёт и таймер прижаты к полю, а кнопка паузы одиноко висит в углу. Настоящие игры раскладывают интерфейс иначе, и в этом шаге разберёмся, как.

## Привязка к краям

Посмотрите на любую мобильную игру. Интерфейс прижат к **краям экрана**: таймер в левом верхнем углу, кнопки в правом, счёт по центру сверху. А игровое поле занимает всё, что осталось между полосами интерфейса. Тогда на любом экране интерфейс там, где игрок привык его искать, а поле — максимально крупное.

Для каждого элемента нужно ответить: к чему он привязан и с каким отступом.

| Элемент | Привязка | Позиция |
|---|---|---|
| Таймер | левый верхний угол | `(MARGIN, TOP_BAR / 2)`, якорь слева |
| Счёт | центр верхней полосы | `(width / 2, TOP_BAR / 2)` |
| Пауза | правый верхний угол | `(width − MARGIN − половина кнопки, TOP_BAR / 2)` |
| Подсказка | центр нижней полосы | `(width / 2, height − BOTTOM_BAR / 2)` |
| Поле | центр свободного места | между полосами, с масштабом «вписать» |

Позиции от правого и нижнего края считаются через `width` и `height`: `width − отступ`. Поэтому при изменении размера экрана правая кнопка остаётся у правого края.

## Масштаб «вписать»

Поле должно занять свободное место между полосами, но не исказиться. Это знакомая по CSS задача `object-fit: contain`: из двух масштабов — по ширине и по высоте — берём меньший, тогда поле влезет целиком:

```ts
const scale = Math.min(width / BOARD_AREA_WIDTH, freeHeight / BOARD_AREA_HEIGHT, MAX_BOARD_SCALE);
```

Третье число — верхний предел. На огромном мониторе поле без него заняло бы всю высоту экрана, и фишки стали бы размером с ладонь. В оригинале поле не масштабируется вовсе: там минимальный размер экрана сделан как раз под поле. Мы позволяем полю расти, но не больше чем в полтора раза.

Масштабировать поле безопасно: события указателя пересчитываются через трансформации, как вы видели в главе 6, а всплывающие «+30» лежат внутри поля и масштабируются вместе с ним.

## Новая функция layout

Замените `layout` целиком:

```ts main.ts
// --- Раскладка: интерфейс у краёв экрана, поле — в свободном месте между ними ---
/** Отступ интерфейса от краёв экрана */
const MARGIN = 16;
/** Высота полосы интерфейса сверху и снизу */
const TOP_BAR = 80;
const BOTTOM_BAR = 80;
/** Поле с рамкой и небольшим запасом */
const BOARD_AREA_WIDTH = BOARD_WIDTH + 40;
const BOARD_AREA_HEIGHT = BOARD_HEIGHT + 40;
/** Больше этого поле не увеличиваем: на огромном мониторе фишки стали бы гигантскими */
const MAX_BOARD_SCALE = 1.5;
/** Ширина счёта с запасом на четыре цифры: «Очки: 9999» */
const SCORE_MAX_WIDTH = 160;

function layout(width: number, height: number) {
  // Верхняя полоса: таймер прижат к левому краю, пауза — к правому
  const barY = TOP_BAR / 2;
  timerText.position.set(MARGIN, barY);
  pauseButton.position.set(width - MARGIN - 67 / 2, barY);
  // Счёт по центру, но на узком экране сдвигаем его левее, чтобы не наехал на кнопки
  const buttonsLeft = pauseButton.x - 67 / 2;
  scoreText.position.set(Math.min(width / 2, buttonsLeft - 8 - SCORE_MAX_WIDTH / 2), barY);

  // Нижняя полоса: подсказка по центру, переносы по ширине экрана
  hintText.style.wordWrapWidth = Math.min(width - MARGIN * 2, 420);
  hintText.position.set(width / 2, height - BOTTOM_BAR / 2);

  // Поле — по центру свободного места, с масштабом «вписать»
  const freeHeight = height - TOP_BAR - BOTTOM_BAR;
  const scale = Math.min(width / BOARD_AREA_WIDTH, freeHeight / BOARD_AREA_HEIGHT, MAX_BOARD_SCALE);
  board.scale.set(scale);
  board.position.set(width / 2, TOP_BAR + freeHeight / 2);
}
```

Разберём то, чего не было в таблице:

- **счёт и кнопки** — на узком экране счёт ровно по центру наехал бы на кнопку паузы, а в следующем шаге рядом с ней появится ещё одна. Поэтому позиция счёта — центр экрана, но не правее точки, где счёт самой большой ширины ещё не касается кнопок. `Math.min` выбирает то, что левее. Ширину берём с запасом, а не текущую: иначе при росте счёта надпись сдвинулась бы только при следующем ресайзе;
- **переносы подсказки** — ширина переноса тоже зависит от экрана: на узком телефоне подсказка переносится чаще, на широком — реже, но не шире 420 пикселей, чтобы строки не стали слишком длинными для чтения. Изменение `style.wordWrapWidth` перерисовывает текст;
- **порядок** — сначала пауза, потом счёт: позиция счёта зависит от кнопки.

::: task
Перепишите `layout`: таймер, счёт и пауза — в верхней полосе у краёв экрана, подсказка — в нижней, поле — по центру свободного места с масштабом «вписать», не больше 1,5.
:::

## Что получилось

В превью таймер переехал в левый верхний угол, счёт — по центру сверху, а поле стало чуть крупнее и заняло место между полосами. Потяните границу превью. Сузьте его — счёт сдвинется левее кнопки паузы, а поле уменьшится. Расширьте — поле вырастет.

Наша проверка измерила масштаб поля на трёх размерах окна: 1,01 на телефоне 375 × 667, 1,10 в превью 500 × 600 и 1,31 на мониторе 1280 × 800. Ни один элемент не вышел за край экрана.

## Эксперименты

- Поставьте `MAX_BOARD_SCALE = 1` и растяните превью пошире. Поле перестанет расти, как было раньше.
- Замените позицию счёта на просто `width / 2` и сузьте превью насколько получится. Счёт наедет на кнопку паузы.
- Поставьте `TOP_BAR = 140`. Полоса интерфейса стала выше, а поле — меньше: свободного места убавилось.

::: deep Под капотом: раскладка в PixiJS и в браузере
В HTML раскладку делает браузер: flexbox, grid, проценты, `margin: auto`. В PixiJS ничего этого нет. Сцена — это координаты, и все правила вида «прижать к правому краю» или «вписать» вы пишете сами, обычно в функции `resize` или `layout` каждого экрана. Так устроен и оригинал: у каждого экрана есть метод `resize(width, height)`, который вызывает навигация.

Для сложных интерфейсов есть библиотека `@pixi/layout`, которая приносит в PixiJS flexbox на движке Yoga. Но для игрового экрана с десятком элементов ручная раскладка проще, нагляднее и не тянет зависимостей. Мы будем делать её вручную.
:::
