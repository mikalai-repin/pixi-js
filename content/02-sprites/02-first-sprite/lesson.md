Текстура загружена, но это только данные на видеокарте. Чтобы она появилась на экране, нужен объект, который скажет: «нарисуй эту текстуру вот здесь, вот такого размера». Такой объект называется **спрайт**.

## Что такое спрайт

**Спрайт** (`Sprite`) — это объект сцены, который рисует текстуру. У него есть позиция, размер, поворот, прозрачность и другие свойства, которые мы разберём в этой главе. Слово пришло из старых игр: так называли маленькие картинки персонажей, которые двигались поверх фона.

Важно различать:

| | Текстура | Спрайт |
|---|---|---|
| Что это | Картинка в памяти GPU | Объект на сцене |
| Сколько их | Одна на картинку | Сколько угодно |
| Знает о позиции | Нет | Да |

Одну текстуру могут использовать тысячи спрайтов одновременно, каждый со своей позицией и поворотом. Именно так работало демо в начале курса: шесть текстур и 60 спрайтов.

## Создаём и добавляем на сцену

```ts main.ts {1,11-12}
import { Application, Assets, Sprite, Texture } from 'pixi.js';

const app = new Application();
await app.init({ background: '#1e1035', resizeTo: window, antialias: true });
document.body.appendChild(app.canvas);
globalThis.__PIXI_APP__ = app;

const texture = await Assets.load<Texture>('/assets/game/piece-dragon.png');
console.log('Текстура:', texture.width, '×', texture.height);

const dragon = new Sprite(texture);
app.stage.addChild(dragon);
```

Строк две, и обе важны:

1. `new Sprite(texture)` создаёт спрайт. Он уже существует, но пока не на сцене.
2. `app.stage.addChild(dragon)` добавляет его в сцену. Только теперь рендерер будет рисовать его каждый кадр.

::: task
Создайте спрайт из загруженной текстуры и добавьте его на сцену.
:::

## Что получилось

В **левом верхнем углу** превью появилось зелье-дракон. Почему именно там, разберём в следующем шаге.

Поэкспериментируйте:

- закомментируйте `app.stage.addChild(dragon)`: зелье исчезнет, хотя спрайт по-прежнему существует;
- создайте второй спрайт из той же текстуры и тоже добавьте на сцену. Ничего не изменится: второй спрайт встанет ровно поверх первого. Позицию мы ещё не задавали, и оба стоят в одной точке.

::: tip
В оригинальной игре вы часто встретите короткую запись `Sprite.from('piece-dragon')`. Она создаёт спрайт по имени уже загруженной текстуры. Это удобно, но работает только для ресурсов, которые загружены заранее и зарегистрированы под коротким именем (псевдонимом). Как это устроено, разберём в главе 5. Пока создаём спрайты явно, через `new Sprite(texture)`.
:::

::: deep Под капотом: что значит «добавить на сцену»
`addChild` не копирует спрайт и не рисует его сразу. Он просто записывает спрайт в массив `app.stage.children` и запоминает у спрайта родителя: `dragon.parent === app.stage`. Каждый кадр рендерер обходит дерево от `stage` вниз и рисует всех, кого найдёт. Спрайт, у которого нет пути до `stage`, рендерер просто не видит.

Если добавить один и тот же спрайт в два разных места, он не раздвоится: у объекта может быть только один родитель, и второй `addChild` перенесёт его на новое место.
:::
