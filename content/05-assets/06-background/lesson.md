Бандлы позволяют не грузить всё сразу. Но если грузить следующий бандл только тогда, когда он понадобился, игрок будет видеть экран загрузки при каждом переходе. Лучше всего — догружать ресурсы **заранее, пока игрок занят**. Это называется фоновой загрузкой.

## `backgroundLoadBundle`

```ts main.ts
// Пока игрок смотрит на поле, тихо догружаем остальные бандлы
Assets.backgroundLoadBundle(['common', 'home', 'result']);
```

Обратите внимание: **без `await`**. Метод запускает загрузку и сразу возвращает управление. Загрузка идёт сама по себе, по одному файлу за раз, чтобы не мешать тому, что грузится в основном режиме.

Самое полезное свойство фоновой загрузки: она **совместима с обычной**. Если позже вызвать `await Assets.loadBundle('common')`:

- если бандл уже загружен в фоне, промис выполнится мгновенно;
- если загрузка ещё идёт, `loadBundle` подхватит её, а не начнёт заново;
- если фоновая загрузка до него ещё не дошла, `loadBundle` загрузит его сразу, в полную силу.

Так работает и оригинальная игра. В `utils/assets.ts` после загрузки бандла `preload` стоит:

```ts
// Start up background loading of all bundles
Assets.backgroundLoadBundle(allBundles);
```

А навигация перед показом каждого экрана вызывает `loadBundles(ctor.assetBundles)`. Чаще всего к этому моменту всё уже загружено.

## Кнопка паузы из `common`

Проверим на деле. Добавьте фоновую загрузку в конец файла, а потом, как будто «через какое-то время» понадобилась кнопка паузы из бандла `common`, загрузите его обычным способом и замерьте время:

```ts main.ts
// Позже понадобилась кнопка паузы из бандла common: он уже загружен или догружается в фоне
const startTime = performance.now();
await Assets.loadBundle('common');
console.log(`Бандл common готов через ${Math.round(performance.now() - startTime)} мс`);

const pauseButton = new Sprite(Texture.from('icon-pause'));
pauseButton.label = 'pauseButton';
pauseButton.anchor.set(1, 0);
pauseButton.position.set(app.screen.width - 16, 16);
app.stage.addChild(pauseButton);
```

`anchor.set(1, 0)` — якорь в правом верхнем углу картинки. Так кнопку удобно прижать к правому верхнему углу экрана: позиция задаёт, где окажется именно этот угол.

::: task
Запустите фоновую загрузку бандлов `common`, `home` и `result`, затем загрузите `common` через `loadBundle` и покажите иконку паузы в правом верхнем углу.
:::

## Что получилось

В правом верхнем углу появилась кнопка паузы из атласа `common`, а в консоли — время ожидания бандла. Скорее всего, это единицы миллисекунд: `loadBundle('common')` подхватил загрузку, которую фоновый загрузчик начал строкой выше.

Чтобы увидеть разницу, включите в DevTools медленную сеть (Slow 4G) и сравните время с фоновой загрузкой и без неё (закомментируйте строку с `backgroundLoadBundle`). В реальной игре между запуском фоновой загрузки и моментом, когда бандл нужен, проходят секунды или минуты: игрок смотрит на главное меню. За это время всё успевает загрузиться.

::: tip
Для отдельных ресурсов есть `Assets.backgroundLoad(['alias1', 'alias2'])`. Работает так же, только по псевдонимам.
:::

::: deep Под капотом: почему по одному файлу
Фоновый загрузчик качает файлы строго по очереди, по одному. Это сделано специально: фоновая загрузка не должна отнимать канал у того, что нужно прямо сейчас. Если игрок нажал «Играть», и игра начала грузить бандл `game` в основном режиме, ему не придётся ждать, пока докачается музыка для экрана результатов.

Когда основной загрузчик запрашивает ресурс, который уже стоит в очереди фонового, ресурс просто перехватывается основным. Отсюда совместимость, которую мы видели выше.
:::
