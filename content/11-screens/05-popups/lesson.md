С главы 6 у нас есть «пауза», которая на самом деле только блокирует поле. Нажмите паузу посреди каскада: фишки продолжают падать, совпадения исчезают, очки растут. Настоящая пауза должна **остановить всё**: анимации, каскад, время. А сверху должен появиться **попап**: окно, которое закрывает экран и ждёт ответа игрока.

## Что изменилось в коде

Перед шагом мы подготовили попапы и переделали под них экран игры:

- **`PausePopup.ts`** — попап паузы: затемнение, панель со скруглёнными углами, заголовок и кнопка «Продолжить». Там же две функции, которые пригодятся всем попапам: `createDim` и `createPanel`;
- **`SettingsPopup.ts`** — бывшая `SettingsPanel`, теперь тоже попап. Она больше не сообщает о настройках колбэками, а записывает их в общий объект;
- **`userSettings.ts`** — этот общий объект: скорость игры и видимость подсказки. Попап настроек его меняет, экран игры читает. Похожий модуль есть и в оригинале;
- **`GameScreen.ts`** — кнопки паузы и настроек в интерфейсе открывают попапы: `navigation.presentPopup(PausePopup)`. Панели настроек внутри экрана больше нет. Появились поля `paused` и `pausedTweens` и пустые методы `pause` и `resume`.

В навигации методы `presentPopup` и `dismissPopup` пока пустые, поэтому кнопка паузы ничего не делает. А в интерфейс `AppScreen` добавлены два необязательных метода — `pause` и `resume`.

## Затемнение

Посмотрите на `createDim` в `PausePopup.ts`:

```ts PausePopup.ts
export function createDim() {
  const dim = new Sprite(Texture.WHITE);
  dim.tint = 0x0a0025;
  dim.alpha = 0.7;
  dim.eventMode = 'static';
  return dim;
}
```

`Texture.WHITE` — встроенная текстура: один белый пиксель. Спрайт с ней, растянутый на весь экран через `setSize`, становится прямоугольником любого цвета благодаря `tint`. Это дешевле, чем `Graphics`: никаких треугольников, обычный спрайт в общем батче.

Важная строка — `eventMode = 'static'`. Затемнение лежит поверх экрана и **ловит все нажатия**. Без неё нажатие «провалилось» бы сквозь полупрозрачный слой на кнопку под ним: система событий ищет самый верхний объект, который принимает события, а неинтерактивные она пропускает.

## Попапы в навигации

Попап — это экран, только он не заменяет текущий, а ложится поверх. Значит, у навигации два слота: `currentScreen` и `currentPopup`. Добавьте поле:

```ts navigation.ts
  /** Попап поверх текущего экрана: пауза, настройки */
  currentPopup?: AppScreen;
```

И напишите методы:

```ts navigation.ts
  /** Показывает попап поверх текущего экрана, а экран ставит на паузу */
  async presentPopup(ctor: AppScreenConstructor) {
    if (this.currentPopup) return;
    if (this.currentScreen) {
      this.currentScreen.interactiveChildren = false;
      this.currentScreen.pause?.();
    }
    this.currentPopup = new ctor();
    await this.addScreen(this.currentPopup);
  }

  /** Закрывает попап и продолжает текущий экран */
  async dismissPopup() {
    const popup = this.currentPopup;
    if (!popup) return;
    await this.removeScreen(popup);
    this.currentPopup = undefined;
    if (this.currentScreen) {
      this.currentScreen.interactiveChildren = true;
      this.currentScreen.resume?.();
    }
  }
```

Попап проходит через те же `addScreen` и `removeScreen`, что и экраны: получает размер, показывается с анимацией, уничтожается. А экран под ним получает `pause` и `resume`. И ещё одна строка — передайте размер попапу в `resize`:

```ts navigation.ts
    this.currentPopup?.resize?.(width, height);
```

Попапы передаются классом, а не именем: `PausePopup` никого не импортирует, кроме навигации, и цикла не возникает.

## Пауза, которая останавливает всё

Что нужно остановить в игре? Время — это просто: метод `update` уже проверяет флаг `paused`. А анимации? Фишки падают твинами GSAP, каскад в `Board` ждёт их промисов. Если заморозить твины, каскад остановится сам: `await` просто не дождётся конца анимации, пока она стоит.

Можно было бы остановить вообще все анимации GSAP: `gsap.globalTimeline.pause()`. Но тогда замёрзнет и анимация появления самого попапа. Нужно остановить только то, что **уже идёт**, а то, что начнётся потом, оставить. Для этого у GSAP есть `gsap.exportRoot()`: он переносит все текущие твины в новую временную шкалу. Новые твины туда не попадают:

```ts GameScreen.ts
  /** Поверх экрана открылся попап: замораживаем анимации и время */
  pause() {
    this.paused = true;
    // Все твины, что идут сейчас, переезжают в одну шкалу, и её можно остановить разом.
    // Твины, созданные после этого (анимация попапа), идут как обычно
    this.pausedTweens = gsap.exportRoot();
    this.pausedTweens.pause();
  }

  /** Попап закрылся: продолжаем с того же места и применяем настройки */
  resume() {
    this.paused = false;
    this.pausedTweens?.resume();
    this.pausedTweens = undefined;
    this.hintText.visible = userSettings.hint;
  }
```

В `resume` экран заодно применяет настройку подсказки: пока был открыт попап настроек, её могли изменить. Скорость попап применяет сам, сразу.

Мы проверили, как ведут себя твины: твин, остановленный через `exportRoot` на середине, после `resume` доигрывает с того же места, и его промис выполняется только тогда. А твин, созданный во время паузы, идёт как обычно.

Напишите в навигации `presentPopup` и `dismissPopup` и передавайте попапу размер экрана. Реализуйте в `GameScreen` методы `pause` и `resume`.
:::

## Что получилось

Сделайте ход и сразу нажмите паузу. Экран затемняется, сверху падает панель «Пауза». Фишки под ней замерли на полпути, таймер стоит. Нажмите «Продолжить»: панель уезжает, и каскад продолжается с того же места. Проверка подтвердила: за 0,7 секунды паузы ни одна фишка не сдвинулась, таймер не изменился, а после продолжения каскад доиграл, и модель с видом совпали.

Кнопка с шестерёнкой открывает настройки уже как попап: под ним игра тоже на паузе. Снимите флажок подсказки и нажмите «Готово» — подсказка исчезнет.

## Эксперименты

- Замените в `pause` две строки с `exportRoot` на `gsap.globalTimeline.pause()`. Нажмите паузу: экран не затемнится, панель не появится, а игра перестанет реагировать на нажатия. Анимация появления попапа тоже замёрзла: затемнение осталось прозрачным, панель — за краем экрана, а навигация ждёт конца `show`, который никогда не наступит. Верните `exportRoot`.
- Уберите у затемнения `eventMode = 'static'` и нажмите на попапе паузы мимо панели, туда, где под затемнением кнопка настроек. Ничего не произойдёт, но только потому, что навигация заблокировала экран игры через `interactiveChildren`. Затемнение — вторая линия защиты: на нём, например, можно закрывать попап по нажатию мимо панели.

::: deep Под капотом: что именно делает exportRoot
Все твины GSAP — дети одной корневой временной шкалы `gsap.globalTimeline`. Её «часы» двигает тикер GSAP, а каждая дочерняя анимация берёт время у родителя. `exportRoot()` создаёт новую шкалу, переносит в неё всех текущих детей корня (с их положением во времени) и ставит новую шкалу в корень на их место. Если остановить новую шкалу, остановятся все её дети. А твины, созданные позже, попадают прямо в корень и идут как обычно.

Оригинал решает ту же задачу иначе: у каждой фишки есть методы `pause` и `resume`, которые останавливают именно её твины, а очередь шагов каскада `AsyncQueue` умеет вставать на паузу между шагами. Это точнее, но требует, чтобы каждый объект с анимациями умел останавливаться. `exportRoot` проще и подходит, когда «остановить всё, что идёт» — именно то, что нужно.
:::
