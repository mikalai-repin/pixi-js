Хватит двух зелий: пора собрать настоящее игровое поле. В Puzzling Potions оно состоит из **9 строк и 7 столбцов**, а размер клетки — **50 пикселей**. Возьмём те же числа.

## Строки и столбцы

Игровое поле — это таблица. Каждую клетку описывают два числа:

- **строка** (`row`) — номер по вертикали, сверху вниз, от `0` до `8`;
- **столбец** (`column`) — номер по горизонтали, слева направо, от `0` до `6`.

```
         column →
         0   1   2   3   4   5   6
row  0   ·   ·   ·   ·   ·   ·   ·
 ↓   1   ·   ·   ·   ·   ·   ·   ·
     2   ·   ·   ·   ·   ·   ·   ·
     …
     8   ·   ·   ·   ·   ·   ·   ·
```

::: warning
Не путайте порядок. В математике и графике пишут `(x, y)`: сначала горизонталь. В таблицах и массивах — `[row][column]`: сначала строка, то есть вертикаль. `row` соответствует `y`, а `column` — `x`. Это классический источник багов в играх на сетке, поэтому в курсе мы всегда называем переменные `row` и `column`, а не `i` и `j`.
:::

Чтобы перевести клетку в пиксели, достаточно умножить её номер на размер клетки:

```
x = column × TILE_SIZE
y = row × TILE_SIZE
```

## Заполняем поле

Замените весь код после загрузки текстур: дракон, лягушка, `printTree` и вывод координат больше не нужны. Вместо них — константы и двойной цикл:

```ts main.ts
const ROWS = 9;
const COLUMNS = 7;
const TILE_SIZE = 50;

const board = new Container();
board.label = 'board';
board.position.set(app.screen.width / 2, app.screen.height / 2);
app.stage.addChild(board);

for (let row = 0; row < ROWS; row++) {
  for (let column = 0; column < COLUMNS; column++) {
    const name = PIECES[Math.floor(Math.random() * PIECES.length)];
    const piece = new Sprite(textures[pieceUrl(name)]);
    piece.label = `${name} [${row}, ${column}]`;
    piece.anchor.set(0.5);
    piece.setSize(TILE_SIZE - 4);
    piece.position.set(column * TILE_SIZE, row * TILE_SIZE);
    board.addChild(piece);
  }
}

console.log('Фишек на поле:', board.children.length);
```

Разберём неочевидное:

- `Math.floor(Math.random() * PIECES.length)` — случайное целое от `0` до `5`, индекс случайного зелья;
- `TILE_SIZE - 4` — зелье чуть меньше клетки, чтобы между соседями оставался зазор в 4 пикселя. В оригинале то же самое: `this.image.width = opts.size - 8`;
- `label` с координатами клетки пригодится при отладке: в DevTools сразу видно, какая фишка где стоит.

Удалите код с драконом и лягушкой и заполните `board` сеткой 9 × 7 из случайных зелий.
:::

## Что получилось

В консоли `Фишек на поле: 63`, а в превью… поле съехало вправо вниз, и бо́льшая часть ушла за край экрана.

Причина та же, что со спрайтом без якоря в прошлой главе. Точка `(0, 0)` контейнера `board` стоит в центре экрана, и от неё сетка растёт **вправо и вниз**: первая фишка в центре экрана, последняя — на 300 пикселей правее и на 400 ниже. Нам нужно, чтобы в точке `(0, 0)` был центр **поля**. Исправим это в следующем шаге.

Пока поэкспериментируйте:

- запустите код несколько раз: поле каждый раз новое;
- поменяйте `ROWS` и `COLUMNS`: например, 4 × 4;
- поставьте `TILE_SIZE = 30`: фишки уменьшатся и сблизятся, потому что и размер, и позиции зависят от одной константы.

::: tip
Одна константа для размера клетки вместо «магических» чисел — первый шаг к тому, чтобы поле легко подстраивалось под экран. Если бы мы написали `piece.setSize(46)` и `column * 50`, при изменении размера пришлось бы искать и менять оба числа.
:::
